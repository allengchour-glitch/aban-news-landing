Border-Radius generieren

Abgerundete Ecken per Regler einstellen — alle gemeinsam oder einzeln, in px oder Prozent — live sehen und den fertigen border-radius-Code kopieren. Alles lokal im Browser, nichts wird gesendet.

CSS 

    
Bei „Alle Ecken gemeinsam" steuert der erste Regler alle vier. In Prozent (bis 50 %) entstehen elliptische Ecken — 50 % an allen Ecken ergibt ein Oval bzw. einen Kreis. Der Code wird zu einem kurzen border-radius zusammengefasst, wenn möglich. Alles lokal, kein Upload.
