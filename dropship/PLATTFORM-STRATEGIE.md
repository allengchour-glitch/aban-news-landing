# 📱 LuxeStyle — Plattform-Strategie (jedi einzeln polishe, anders vorgah)

> User 2026-06-17 „jedi einzele Social-Media polishe und anders vorgah?" — JA. Jede Plattform hat
> eigenen Algo + Publikum → eigener Content-Stil, eigene Caption, eigenes Format. NICHT überall dasselbe.

## 🎵 TikTok (@luxestyle.ch)
- **Format:** churzi vertikali Reels (8–15 s), schnäll, nativ. **STUMM hochlade** → Trend-Sound in der App drauf (lizenzrechtlich nur in-app).
- **Hook:** 1. Sekunde, **Mundart** + Preis-Anker (Gewinner: Produkt+CHF, Ø 793 V). Kei schwers Branding-Overlay (wirkt wie Ad → weniger Reach).
- **Caption:** churz, 3–5 CH-Hashtags (#schweiz #fyp #schweizmode + Stadt).
- **Gewinner-Content:** Schmuck-Makro, Kleid-in-Bewegung. **Verlierer:** generischi Street-Shots.
- **Wachstum:** Follower langsam (ch-follower-growth, Cap 22/Tag). Posten via PC-Brave-Port.

## 📸 Instagram (@luxestyle.ch)
- **Format-Mix:** polierti **Reels MIT Musik** (eigeni, eingebacke) · **Carousels** (Bilderreihe/1 Kachel, swipebar, editorial Text-Karte) Di+Fr · **Stories** (täglich, ephemer).
- **Caption:** ästhetisch, Mundart+Hochdeutsch gmischt, 5–8 Hashtags + 1 CTA + Code WELCOME10.
- **Grid-Polish:** konsistenti Text-Karte (LUXESTYLE-Wortmarke + Pill). Kei nackti Lieferanten-Bilder.
- **Engagement:** Kommentar-Auto-Antwort (Worker), DMs (PC-Browser), jederzeit.

## 👍 Facebook (LuxeStyle CH)
- **Publikum älter** → **längeri Caption** OK, mehr Text/Story, Link-Posts zum Shop.
- **Format:** Reels + Stories (via Worker) + Foto-Posts. **Community/Gruppen-Posts** (CH-Mode-Gruppen) = Gratis-Reichweite.
- **Caption:** ausführlicher, Nutzen + Trust (Gratis-Versand/TWINT/Rückgabe) + Link.

## 📌 Pinterest (bestehendes System)
- **Format:** **hochi Pins** (2:3), SEO-**Keywords** im Titel/Beschreibung (Pinterest = Suchmaschine!).
- **Caption:** keyword-reich (z.B. „Silber Herzkette Schweiz", „Sommer Outfit Damen"), Produkt-Link direkt.
- **Cadence:** 2×/Woche (Mo+Do), idempotent (`pinterest_publish.mjs`).

## 🧩 Gemeinsam (alle)
- **NIE:** Botox/Serum/fremd-gebrandeti Öl-Flasche, asiat. Schrift, Watermark, Fake-Reviews. Vor JEDEM Post Bild ansehen.
- **STRIKT Schweiz**, kei Deutschland. Mundart bevorzugt (filtert DE raus).
- **Videos IMMER mit Beschreibung** (Reichweite/SEO).
- **Safe-Zone-Text** (endet ~y≤1500), kein Text ganz unten.
- **Pro Plattform getrennt lernen** (eigene Hashtag-Pools/Hooks im Gehirn).

## 🔁 Umsetzung (Stand)
