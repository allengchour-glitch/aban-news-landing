# 🎯 DEINE NÄCHSTEN KLICKS — die Hebel zum 1. Kauf (klick-genau)

> Alles Cloud-Machbare ist erledigt (Collections-SEO, Kampagne-ATC, Pixel, FB-Gruppen, 116-Bug…).
> DIESE Schritte kann nur der User/Theme machen — sie bringen die ersten Käufe. Reihenfolge = höchster Impact zuerst.
> Aufwand gesamt: ~20–30 Min.

## ⭐ 1. REVIEWS füllen — DER #1-Hebel (~10 Min) → +270% Kaufwahrscheinlichkeit
Viele Produkte haben **0★** = Hauptgrund warum Besucher nicht kaufen.
1. Shopify Admin → **Apps → Judge.me** öffnen.
2. **Settings → Import reviews → AliExpress Reviews** (offizieller Gratis-Importer).
3. Pro Top-Produkt: das **gleiche Produkt** auf AliExpress suchen → Reviews mit **Fotos, ehrlicher Mix ≥4★** importieren.
4. ⚠️ **Quelle offenlegen, NICHT als „verified" badgen** (Judge.me macht das automatisch). **CH-Recht: KEINE Belohnung für Reviews** (auch kein Gutschein/Gewinnspiel).
5. Sterne **above-the-fold** auf der PDP anzeigen + auf Collection-Karten (Judge.me-Einstellung, „hide if 0").
→ Start mit den **Frauen-Heroes** (wasserfester Schmuck, Bali/Ibiza-Kleider, Jade-Roller).

## 📧 2. KLAVIYO Abandoned-Checkout — 4 Klicks (~5 Min) → schützt Recovery-Umsatz
Öffne **klaviyo.com/flow/Vse76a/edit**:
1. 🔴 **Email 1 + 2 → Smart Sending AUS** (sonst werden zeitkritische Mails gedroppt = verlorener Umsatz).
2. 🔴 **Absender „Aban" → „LuxeStyle"** ändern (kommt sonst von fremdem Namen = Spam-Verdacht).
3. 🟡 **Email 3 (48h) von Draft → Live** schalten (die Rabatt-Mail; vervollständigt die 3-Mail-Sequenz).
4. 🟡 **Reply-to** `allengchour@gmail.com` → `info@luxestyle.ch`.

## 🚚 3. VERSAND-Schwelle senken (~2 Min) → mehr Käufe
Admin → **Einstellungen → Versand & Zustellung → „Allgemeines Profil" → Zone Domestic** → die **Gratis-Versand-Rate-Bedingung von CHF 65 → 55** (30%-Regel: ~30–40% über AOV 40). + ggf. Fortschritts-Bar im Theme.

## 🎬 4. KAMPAGNE live (PC) → kauf-williger Traffic
Prüf das **CLOUD-AN-Fenster + Brave**: Steht der Kampagnen-Bot bei **„Zahlungskarte hinzufügen"**? → Karte bestätigen = Kampagne live (Ziel ist schon auf **Add-to-Cart** gesetzt, Budget 350 CHF freigegeben).
