# LuxeStyle — Affiliate-Programm (UpPromote) · Start-Kit

Alles zum sofortigen Loslegen, sobald die UpPromote-App installiert ist.
Provision wird nur bei **echtem Verkauf** fällig — kein Fixkosten-Risiko.

---

## 1) Programm-Eckdaten (in UpPromote eintragen)

| Einstellung | Wert | Warum |
|---|---|---|
| **Provision** | **15 %** vom Bestellwert | Bei CJ-Marge gut tragbar, für Creator attraktiv |
| **Tracking** | Coupon **+** Referral-Link | Code für Stories/Reels, Link für Bio/Beschreibung |
| **Cookie-Laufzeit** | 30 Tage | Käufe nach Klick werden 30 Tage zugeordnet |
| **Auszahlung** | PayPal (ab CHF 30 Guthaben) | Automatisch, kein manueller Aufwand |
| **Eigener Code je Affiliate** | z. B. `ANNA15`, `LARA15` | Verkäufe sauber zuordenbar |
| **Bonus-Anreiz (optional)** | Erste 3 Verkäufe = 20 % | Motiviert zum schnellen Start |

**Bedingungen (kurz, für die Programm-Beschreibung):**
- Nur ehrliche Empfehlung echter Produkte, kein Spam.
- Kein Bieten auf Marken-Keywords / keine bezahlte Werbung auf „LuxeStyle".
- Auszahlung nach 14-tägiger Rückgabefrist der zugeordneten Bestellung.
- Provision auf Produktwert (ohne Versand/Steuern).

## 3) Wo finde ich passende Schweizer Creator?

**Zielgrösse:** 1.000–20.000 Follower („Mikro/Nano") — antworten am ehesten,
authentisch, günstig. Grosse Accounts ignorieren DMs meist.

**Suchen auf Instagram & TikTok nach Hashtags:**
- `#swissfashion` `#schweizmode` `#fashionschweiz` `#ootdschweiz`
- `#swissblogger` `#swissinfluencer` `#zürichstyle` `#fashionsuisse`
- `#modeschweiz` `#swissgirl` `#outfitinspo` (+ Standort: Zürich/Bern/Basel)

**Auswahl-Kriterien (kurz prüfen):**
- ✅ Echte Engagement-Rate (Kommentare, nicht nur Likes)
- ✅ Damenmode/Lifestyle-Fokus, Zielgruppe = junge Frauen CH
- ✅ Postet regelmässig, sauberer Feed
- ❌ Gekaufte Follower (viele Follower, kaum Kommentare) → überspringen

**Tipp:** Pro Tag 5–10 DMs schicken. Realistisch antworten ~20–30 %, davon machen
einige mit. Mit 5–8 aktiven Mikro-Creatorn hast du einen guten, kostenlosen Kanal.

## Ablauf in Kürze
1. UpPromote installieren → Programm mit obigen Werten anlegen.
2. Registrierungs-Link aus UpPromote kopieren (`luxestyle.ch/pages/affiliate` o. ä.).
3. 5–10 Creator per DM (oben) anschreiben → Link schicken.
4. Creator registrieren sich → App erstellt Code + Link automatisch.
5. Verkäufe + Provisionen laufen automatisch über die App.
