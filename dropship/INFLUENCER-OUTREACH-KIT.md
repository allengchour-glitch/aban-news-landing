# 🎁 Influencer-Outreach-Kit — LuxeStyle CH (Micro-Gifting)

> **Prinzip:** Schweizer Micro-Creator (1.000–20.000 Follower) bekommen **ein Produkt gratis** —
> kein Geld. Wenn es gefällt, posten sie ehrlich. Jede:r kriegt einen **eigenen Rabattcode** →
> du siehst genau, wer Verkäufe bringt. Kosten = nur Wareneinsatz. Bester Hebel pro Franken.

---

## 1) Wen suchen (Vetting-Kriterien)
- **1.000–20.000 Follower** (Micro = höchstes Engagement, antwortet eher).
- **Nische:** Fashion / Lifestyle / Beauty / „Mom & Style" / Swiss-Living.
- **Echte Kommentare** (nicht nur Likes) — Engagement **2–8 %** ist top.
- **Schweiz-Bezug** (Bio/Standort CH, deutsch- oder westschweizer Content).
- **Lieber 10 kleine engagierte als 1 grosser toter Account.**

## 2) Wo finden (TikTok + Instagram Suche)
Suche diese Hashtags/Begriffe → Tab **„Neueste"** → die mit echtem Engagement anschreiben:
`#schweizmode` · `#swissfashion` · `#ootdschweiz` · `#swissblogger` · `#baselfashion` ·
`#zurichstyle` · `#swissmom` · `#switzerlandstyle` · `#fashionschweiz` · `#swissinfluencer` ·
`#bernstyle` · `#luzern` · `#suissestyle` (Westschweiz) · `#genevastyle`

> Tipp: Wer kürzlich gepostet hat **und** im Kommentarbereich antwortet, reagiert auch auf deine DM.
> 15–20 Kandidat:innen sammeln → in die Tracking-CSV eintragen → 2–3 DMs/Tag senden (nicht alle auf einmal).

## 3) DM-Vorlagen (kopieren & Namen einsetzen)

**Erstkontakt (Instagram/TikTok DM):**
```
Hey [Name] 🤍 Ich bin Allen von LuxeStyle, einem kleinen Schweizer Online-Shop.
Dein Content passt perfekt zu uns! Ich würde dir gern ein Teil deiner Wahl GRATIS
schicken — ohne Verpflichtung. Wenn's dir gefällt, freue ich mich über eine ehrliche
Story/einen Post, aber kein Muss. Magst du? Schau gern auf luxestyle.ch 🇨🇭
```

**Nach „Ja" (Produkt + Adresse + Code):**
```
Super, freut mich! 🙌 Such dir auf luxestyle.ch ein Teil aus (bis ~CHF 60) und
schick mir Link + Grösse + Lieferadresse. Du bekommst ausserdem deinen eigenen
Code [NAME10] = −10 % für deine Community. Versand 8–14 Tage, ich halte dich auf dem Laufenden 🤍
```

**Sanftes Follow-up (nach 4–5 Tagen ohne Antwort — EINMAL, dann Ruhe):**
```
Hey [Name], kein Stress — falls Interesse besteht, das Gratis-Teil steht weiter bereit 🙂
Lieben Gruss aus der Schweiz, Allen
```

**Regeln:** kein Geld · ehrlich (keine Fake-Werbung erzwingen) · ein eigener Code pro Creator ·
nie mehr als 1 Follow-up · authentisch & locker schreiben.

## 4) Codes & Tracking
- **Code-Schema:** Vorname + 10, z.B. `ANNA10`, `LARA10` (10 % Rabatt, kein Mindestwert).
- Trag jede:n in **`dropship/influencer_tracking.csv`** ein → Status pflegen (kontaktiert → zugesagt →
  versendet → gepostet → Verkäufe). So siehst du nach 2–3 Wochen, welche Creator wirklich liefern.
- **Sag mir „Code [NAME] anlegen"** → ich erstelle den Rabattcode direkt im Shop (Shopify), sobald ein:e
  Creator zusagt. (Codes lege ich erst bei Zusage an, nicht auf Vorrat.)

## 5) Realistischer Rhythmus
- **2–3 DMs/Tag** (nicht mehr → wirkt sonst wie Spam/Bot).
- **1×/Woche** 5 neue Kandidat:innen recherchieren & nachlegen.
- Geduld: aus 20 DMs werden grob 3–6 Kooperationen → davon 1–2 echte Verkaufsbringer. Dranbleiben gewinnt.

## Was ich liefere vs. was nur du kannst
- ✅ **Ich:** Kriterien, Such-Hashtags, DM-Vorlagen, Tracking-Sheet, Rabattcodes im Shop anlegen (auf Zuruf).
- 🙋 **Nur du:** Accounts durchsehen & auswählen, DMs senden (kein offizielles API-Senden möglich),
  Gratis-Produkt verschicken.
