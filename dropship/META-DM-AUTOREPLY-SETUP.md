# 💬 Instagram-DM-Auto-Antwort — Meta Business Suite (gratis, ohne API/Review)

> Der einzige offizielle Weg, der OHNE App-Review funktioniert. Reine Klick-Einstellung in der
> App / im Meta Business Suite — kein Token, kein Code. Dauer: ~5 Min. Ehrliche Claims (8–14 Tage, weltweit).

## Wo
- **Handy:** Instagram-App → Profil → ☰ → **Einstellungen** → **Business/Unternehmen** → **Automatische Antworten / Gespeicherte Antworten**
- **Desktop:** business.facebook.com → **Postfach** → ⚙️ **Automatisierte Antworten**

## 1) Sofort-Antwort (1. Nachricht) — EINSCHALTEN
```
Hey 🤍 Danke für deine Nachricht! Wie können wir helfen?
Schreib uns gern: Versand, Grösse, Preis oder Verfügbarkeit ✨
Alle Looks → luxestyle.ch · −10% mit Code WELCOME10
```

## 2) Abwesenheits-Nachricht (nachts/Wochenende) — optional
```
Hey 🤍 Danke dir! Wir sind nicht immer sofort da, melden uns aber bald.
In der Zwischenzeit: alle Infos & Looks auf luxestyle.ch · −10% mit WELCOME10 ✨
```

## 3) FAQ / Stichwort-Antworten (das Herzstück) — je Stichwort eine Regel
| Stichwörter | Antwort |
|---|---|
| versand, lieferung, wann, paket | `📦 Weltweiter Versand, 8–14 Werktage · gratis ab CHF 65. Sendungsverfolgung inklusive 🤍 luxestyle.ch` |
| grösse, size, passt, masse | `👗 Die Grössentabelle steht direkt beim Produkt auf luxestyle.ch — sag uns gern, welches Teil! 🤍` |
| preis, code, rabatt, welcome10 | `💛 Mit Code WELCOME10 bekommst du −10% auf deine erste Bestellung → luxestyle.ch` |
| verfügbar, lager, farbe, ausverkauft | `🤍 Verfügbarkeit + alle Farben siehst du live auf luxestyle.ch ✨` |
| rückgabe, retoure, zurück | `🔄 30 Tage Rückgaberecht, unkompliziert. Schreib uns einfach, wir kümmern uns 🤍` |
| zahlung, twint, paypal, karte | `💳 Du kannst mit TWINT, Kreditkarte oder PayPal bezahlen — sicher im Checkout 🤍` |
| link, shop, kaufen | `🛍️ Hier entlang → luxestyle.ch · mit WELCOME10 −10% 🤍` |

## 4) Kommentar → DM (Wachstums-Hebel) — falls im Business Suite verfügbar
- Trigger: Kommentar enthält `LINK`
- Auto-DM:
```
Da ist er 🤍 → luxestyle.ch · Mit Code WELCOME10 −10% auf deine erste Bestellung ✨
Weltweiter Versand, gratis ab CHF 65 📦
```

## Hinweis
- Reine Stichwort-Automatik (keine echte KI) — für smarte/KI-Antworten bräuchtest du ManyChat
  (auch ohne Review, siehe MANYCHAT-FLOWS.md). Aber für den Start reicht das hier vollkommen.
- Den 1 offenen Chat: einfach mit der Sofort-Antwort oben beantworten.
