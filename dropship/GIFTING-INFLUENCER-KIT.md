**Natürlichsprachlich (für Lessie/Janney/Modash-AI-Suche):**
```
Find micro-influencers based in Switzerland, 1,000–20,000 followers, in women's & men's
fashion, lifestyle, beauty or self-care. Engagement rate ≥ 3%. Audience mainly Swiss/DACH,
German or French speaking, 18–40. Content style: outfit/OOTD, hauls, get-ready-with-me,
product reviews. Looking for gifting collaborations (free product in exchange for an honest
post/story). Exclude accounts with fake followers or <2% engagement.
```

**Filter (falls manuell setzbar):**
- Location: **Switzerland** (sek.: Deutschland/Österreich)
- Followers: **1.000–20.000**
- Engagement: **≥ 3%**
- Kategorie: Fashion / Lifestyle / Beauty
- Sprache: DE / FR

**Gratis ohne Tool — Hashtag-Suche (TikTok/IG „Neueste"):**

## 4) 🔁 Ablauf (1×/Woche, ~30 Min)
1. 5–10 Creator finden (Tool oder Hashtag) → Fake-Check.
2. DM senden (Vorlage, Name + 1 persönlicher Satz).
3. Bei „ja": Produkt + eigener Code schicken, Versand ehrlich nennen.
4. In einer Liste tracken: Name · Follower · Code · Status · Verkäufe.
5. Wer performt → langfristige Partnerschaft.

**Realistisch:** von 10 DMs antworten ~3–5, davon posten ~2. Bei 20 Creatorn/Monat = stetiger,
echter Zustrom + Social Proof — viel nachhaltiger als jeder Bot.
