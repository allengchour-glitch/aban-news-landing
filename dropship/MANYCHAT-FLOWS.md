## 1) Ice Breakers (IG — die antippbaren Fragen oben im Chat)

## 5) Comment → DM (der Wachstums-Hebel 🚀)
ManyChat → Automation → **Instagram → Comments** → neue Regel:
- **Trigger:** Kommentar auf deinen Posts/Reels enthält Keyword `LINK` (oder `MEHR`, `INFO`)
- **Auto-DM (Varianten):**
  1. `Da ist er 🤍 → luxestyle.ch · Mit Code WELCOME10 bekommst du −10% auf deine erste Bestellung ✨ Weltweiter Versand, gratis ab CHF 65 📦`
  2. `Hier dein Link 🛍️ luxestyle.ch — WELCOME10 = −10%. Schreib mir gern, wenn du Fragen zu Grösse oder Versand hast 🤍`
- **Optional Button:** `🛍️ Jetzt shoppen` → `https://luxestyle.ch`

> Meine Reel-Captions sagen schon „Schreib LINK 👇" — das füttert genau diesen Trigger und treibt
> gleichzeitig die Kommentar-Zahl (gut für den Algorithmus).

## 7) Tonalität (für alle Texte)
- **Du-Form**, herzlich, 1–2 Emojis (nicht mehr), nie aufdringlich.
- **Ehrlich:** „weltweiter Versand 8–14 Werktage" — **nie** „Schweizer Versand".
- Marke = Schweizer Shop ✅, Produkte = weltweit geliefert ✅.
- Bei Unsicherheit/Beschwerde → freundlich an Mensch/Mail weiterleiten, nichts versprechen, was nicht stimmt.

---

## 8) Reihenfolge zum Einrichten (in ManyChat)
1. IG + FB mit ManyChat verbinden (Account → Channels).
2. **Welcome Message** + **Ice Breakers** setzen (Abschnitt 1–2).
3. **Default Reply** setzen (Abschnitt 3).
4. **Keyword-Regeln** anlegen (Abschnitt 4) — pro Thema 1 Regel, alle Keywords + Varianten rein.
5. **Comment→DM** (Abschnitt 5) + **Story-Reply** (Abschnitt 6).
6. Test: dir selbst eine DM / einen Kommentar mit „LINK" schicken → prüfen, ob die Antwort kommt.
