# Tote oder leere Links in der Hauptnavigation

Das Menü ist die Navigation, die jede Besucherin benutzt. Diese Einträge führen ins Leere oder in eine leere Kategorie.

- `/en/pages/alle-kategorien` — Sprachpfad /en/ ist nicht veroeffentlicht → HTTP 404
- `/fr/collections/schmuck-uhren` — Sprachpfad /fr/ ist nicht veroeffentlicht → HTTP 404
- `/fr/collections/schmuck-uhren` — Pfad-Praefix vor /collections/ — liefert 404 (Sprachpfad wie /en/ existiert nicht)
