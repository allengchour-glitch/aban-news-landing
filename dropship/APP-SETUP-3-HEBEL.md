# 🛠️ 3 Conversion-Hebel aktivieren — Link + Anleitung

> Store: luxestyle-ch · Admin: `admin.shopify.com/store/luxestyle-ch`
> Reihenfolge nach Sofort-Wirkung. Gesamt ~25 Min. Alle gratis.

---

## 1️⃣ FILTER (Search & Discovery)  ⭐ grösster Sofort-Effekt, gratis
Filter wie bei MediaMarkt (Preis, Marke, Produkttyp, Verfügbarkeit) — wirkt **sofort**, deine Daten sind schon da.

**Installieren (falls noch nicht):**
- 🔗 https://apps.shopify.com/search-and-discovery → „Installieren" (von Shopify, gratis)

**Einrichten:**
1. Admin → **Apps → Search & Discovery** öffnen
2. Tab **„Filter"** → **„Filter hinzufügen"**
3. Diese hinzufügen: **Verfügbarkeit · Preis · Produkttyp · Marke (Vendor)** (und Farbe/Grösse, falls als Option vorhanden)
4. Speichern → erscheinen automatisch auf allen Kategorie-Seiten ✅

**Bonus im selben Tool:** Tab **„Synonyme"** → z.B. `uhr↔armbanduhr`, `sneaker↔turnschuh`, `handy↔smartphone`, `kopfhörer↔headset` → bessere Such-Treffer.

---

## 2️⃣ STICKY „In den Warenkorb" (mobil)  — gratis
Der Kauf-Button bleibt beim Scrollen sichtbar = mehr Käufe auf dem Handy (wo TikTok/FB-Besucher herkommen).

**Installieren:**
- 🔗 https://apps.shopify.com/sticky-add-to-cart-booster  *(„Sticky Add To Cart Booster", gratis-Tier)*
- Alternative Suche: 🔗 https://apps.shopify.com/search?q=sticky%20add%20to%20cart

**Einrichten:**
1. App installieren → öffnen
2. **„Enable Sticky Add to Cart"** einschalten
3. Auf **Mobil** aktivieren (Desktop optional), Farbe an dein Theme anpassen
4. Speichern → fertig ✅ (kein Theme-Code nötig)

---

## 3️⃣ JUDGE.ME Review-Sterne  — schon installiert, nur aktivieren
⚠️ **Wichtig:** Sterne zeigen sich erst, **wenn es echte Reviews gibt** (kommen mit den ersten Verkäufen). Jetzt aktivieren = bereit, sobald Bewertungen da sind. **Keine Fake-Reviews importieren** (schadet Vertrauen).

**Aktivieren:**
1. Admin → **Apps → Judge.me Product Reviews** öffnen
2. Im Theme: Admin → **Online Store → Themes → Anpassen**
3. Auf **Produktseite** (Vorlage „Produkt"): unter dem Titel → **Block hinzufügen → „Judge.me Review Stars"** (Sterne) + weiter unten **„Judge.me Review Widget"** (Bewertungen)
4. Auf **Kategorie-/Produktkacheln**: in der Produktkarten-Sektion → Block **„Judge.me Star Rating"** hinzufügen
5. Speichern ✅

**Dazu (bringt später echte Reviews):** In Judge.me → **Settings → Review Requests** einschalten → nach jedem Kauf geht automatisch eine Bewertungs-Mail raus.

---

## 🧭 Kürzeste Reihenfolge
1. **Search & Discovery installieren + Filter an** (10 Min) → grösster UX-Sprung
2. **Sticky Add to Cart installieren + an** (5 Min) → Mobil-Conversion
3. **Judge.me-Sterne + Review-Mails an** (10 Min) → zahlt sich mit ersten Verkäufen aus
