## Ehrliche Einleitung — was organisch leistet (und was nicht)

Die eigenen LuxeStyle-Daten und die Branchenrecherche 2025/26 sagen dasselbe: **organischer Social-Traffic konvertiert dünn.** 30-Tage-Stand: ~2.994 Sessions, 38 % social (low-intent), **0 Käufe**. Organische Reichweite ist plattformweit gefallen (Facebook 1–2 %, Instagram org. Reach ca. −12 % YoY, Engagement rückläufig). „Mehr posten" hat bei uns bewiesen **0 Hebel** auf Verkäufe.

**Daraus folgt das ehrliche Ziel dieses Plans:**

- Organisch = **Marke, Vertrauen, Wiedererkennung, Kaufabsicht aufbauen** und Traffic auf den Shop leiten — **kein Sofort-Umsatz-Schalter.**
- Der einzige bewiesene Conversion-Hebel bleiben die **3 User-Klicks** (TikTok-Pixel, bezahlte Conversion-Kampagne 20 CHF/Tag, AGB-Domain). Die kann nur der User setzen.
- Der plausibelste organische **Kauf-Kanal** ist **Pinterest** (intent-stark, evergreen, Pins leben Monate) — nicht IG/TikTok. Siehe `PINTEREST-START-PAKET.md`.
- Wir spielen daher auf **Klasse statt Masse**: wenige starke Posts, konsequent, mit Trust-Content statt Dauerwerbung.

## Cross-Channel-Repurposing-Regel

**1 Hero-Video EINMAL drehen → in native Formate kaskadieren:**

```
9:16 MP4  ──►  TikTok + IG Reel + FB Reel
bester Frame  ──►  4:5 IG-Feed-Post + 1080×1350 Pinterest-Pin
2. Frame  ──►  IG Story (mit Poll/Frage-Sticker)
Caption-Kern  ──►  Threads-Text-Post + Pinterest-Beschreibung
```

Spart 60–80 % Zeit. **Pflicht:** jeder Kanal bekommt **natives Format + eigenen On-Screen-Text** — **kein** TikTok-Repost mit Wasserzeichen auf IG (IG „Originality Score" drosselt recyceltes Material; pro Kanal sauber neu rendern).

## Anti-Doppelpost (1 Poster)

- **Es gibt genau EINEN Poster** (die Posting-Session). Sie postet **jede Kalender-Zeile genau einmal** auf den dort genannten Kanal.
- **Generator-/Render-Sessions liefern nur Vorschläge** in eine Queue (CSV/Draft) — sie posten **nie** selbst.
- Vor dem Posten: gegen das Ledger prüfen (bereits gepostete Slugs/Zeilen überspringen), damit nichts doppelt rausgeht. Deckt sich mit der Memory-Lehre „mehr Auto-Posts = 0-Hebel" → lieber 1× sauber als 2× Spam.

## Realistische Erwartung

- **Organisch = Aufbau** (Marke, Trust, Wiedererkennung, Kaufabsicht), **kein Sofort-Umsatz.** Reichweite ist gefallen, social-Traffic ist low-intent — das ist Branchenrealität *und* unser eigener Befund.
- **Kein KPI-Selbstbetrug:** Erfolg misst sich an **Saves, Shares (DMs), Watch-Time, Pinterest-Klicks** — nicht an Likes. UTM-Links auf alle Bio/Story/Pin-Links, um den (kleinen) organischen Traffic überhaupt messbar zu machen.
- **Der harte Conversion-Hebel bleibt bezahlt:** TikTok-Pixel + Conversion-Kampagne + AGB-Domain (die 3 User-Klicks). Organisch füttert das Vertrauen drumherum.
- **Stärkster nicht-autonomer organischer Hebel:** CH-Micro-Creator-Kollab (10–100k, DE/FR) — als **User-Aufgabe** markieren (Outreach/Vertrag geht nicht im Autopilot).
- Zahlen aus der Recherche sind **Richtwerte, keine Garantien** (z. B. Threads-MAU 175M–400M je Quelle); nicht als zugesicherte Ergebnisse behandeln.
