# 🎨 Customizer-Profi-Anleitung — LuxeStyle von „0815" zu professionell

> Der Shop ist **inhaltlich fertig professionell** (Produkttexte, Grössentabellen, SEO, beschriebene
> Kollektionen, kuratierte Premium-Boutique). Der letzte Schliff ist das **visuelle Theme** — das kann nur
> über den **Shopify-Customizer** gemacht werden (das Live-Theme ist für die API gesperrt). Hier Schritt für Schritt.

**Wo:** Shopify-Admin → **Onlineshop → Themes → [aktives Theme] → Anpassen**. Oben kannst du zwischen
**Mobil 📱 und Desktop 🖥️** umschalten — immer **zuerst Mobil** prüfen (dort kaufen die meisten).
Jede Änderung mit **„Speichern"** (oben rechts) bestätigen.

---

## 1. 🦸 Hero (das erste Bild) — der wichtigste Hebel
Startseite → oberster Abschnitt („Bild mit Text" / „Slideshow").
- **Bild:** ein hochwertiges, ruhiges Mode-Foto (eine Frau im Look, viel Weissraum). Vermeide Collagen/grelle Produktbilder.
  Gute Quelle gratis: pexels.com / unsplash.com (Suchwort „elegant fashion woman beige").
- **Headline:** kurz & klar, z.B. **„Premium-Looks & Marken — fair & schweizweit geliefert"**
- **Unterzeile:** „Mode · Schmuck · Designer-Marken · Gratis-Versand ab CHF 65"
- **Button:** Text „Jetzt entdecken" → Link auf `/collections/neu` oder `/collections/✨-luxestyle-premium`.
- **Höhe:** Mobil „Mittel", Text **linksbündig unten**, dunkles Overlay 20–30 % für Lesbarkeit.

## 2. 🟫 Ankündigungsleiste (oben, schmal)
Theme-Einstellungen → „Ankündigungsbalken“.
- Text: **„🇨🇭 Gratis-Versand ab CHF 65 · 30 Tage Rückgabe · –10 % mit Code WELCOME10“**
- Eine Farbe passend zum Logo, nicht grell. Kein Dauer-Blinken.

## 3. 🟦 Produktkacheln einheitlich (gegen den „0815"-Look)
Theme-Einstellungen → „Produktkarten“ / Abschnitt „Empfohlene Produkte“ & „Kollektion“.
- **Bildverhältnis: „Quadratisch" (square)** für ALLE Produktraster → gleichmässiges, ruhiges Bild.
- **Sekundäres Bild bei Hover anzeigen:** AN (wirkt hochwertig).
- Schrift der Kachel klein/dezent, Preis fett.

## 4. ⭐ Bewertungs-Sterne auf den Kacheln (Trust!)
Du hast **Judge.me** installiert.
- Judge.me-App → **Settings → Widgets → Star Rating** → „Add to collection/product cards" aktivieren.
- Im Customizer ggf. den Judge.me-Block in der Produktkarte + Produktseite einfügen (App-Block „Reviews“).
- Ziel: Sterne erscheinen unter dem Produktnamen im Raster (massiv mehr Vertrauen).

## 5. 🛒 Sticky „In den Warenkorb" (Mobil) + Trust-Icons
Produktseite-Template (Customizer → oben „Produkte → Standardprodukt“).
- Block **„Sticky Add-to-Cart"** / „Kaufleiste" aktivieren (hält den Button beim Scrollen unten sichtbar).
- Direkt beim Button: **Zahlungs-Icons** (TWINT, Visa, Mastercard, PayPal) als Bild/Block einfügen.
- Block „Vertrauens-Abzeichen“: „🇨🇭 Schweizer Shop · 30 Tage Rückgabe · Sichere Zahlung“.

## 6. 🔤 Schriften & Farben (Marken-Konsistenz)
Theme-Einstellungen → „Typografie“ & „Farben“.
- **Max. 2 Schriften:** eine elegante Serifen-Schrift für Überschriften (z.B. „Playfair Display“),
  eine ruhige Sans-Serif für Text (z.B. „Inter“/„Assistant“).
- **Farbpalette dezent:** Creme/Beige-Hintergrund (#FAF7F2), dunkle Schrift (#2C2C2C), 1 Akzent (z.B. Gold/Cognac).
  Keine grellen Knallfarben → wirkt sofort hochwertiger.

## 7. 🧭 Menü / Navigation aufräumen
Admin → Onlineshop → **Menüs** → Hauptmenü.
- Max. **6–7 Hauptpunkte:** Damen-Mode · Schmuck & Uhren · ✨ Premium · Beauty · Wohnen · Sale/Neu.
- Untermenüs nutzen statt 20 Links nebeneinander.

## 8. 🧹 Redundante Kollektionen ausblenden (nur Admin möglich)
Admin → Onlineshop → **Kollektionen**. Es gibt viele überlappende (z.B. „Geschenke unter CHF 50/100“ = fast ganzer
Katalog, mehrere Saison-Kollektionen).
- Bei jeder unnötigen Kollektion: **„Verfügbarkeit verwalten“ → Häkchen bei „Onlineshop“ entfernen** (blendet sie aus,
  ohne zu löschen → reversibel). So bleibt die Navigation sauber. *(Das geht NUR hier im Admin — die API ist dafür gesperrt.)*

## 9. 🦶 Footer professionell
- Spalten: „Über uns / Impressum“ · „Versand & Rückgabe“ · „Kontakt (info@luxestyle.ch)“ · „Zahlungsarten“.
- Social-Icons (Instagram/TikTok/Facebook) verlinken.
- Newsletter-Anmeldung (Klaviyo) sichtbar.

---

## ✅ Reihenfolge für den grössten Effekt
1. **Hero-Bild + Headline** (Punkt 1) — verändert den ersten Eindruck am meisten.
2. **Quadratische Kacheln + Hover** (3).
3. **Judge.me-Sterne auf Kacheln** (4).
4. **Sticky-ATC + Zahlungs-Icons mobil** (5).
5. Schriften/Farben (6), Menü (7), Footer (9), Kollektionen ausblenden (8).

> Wenn du keine Zeit hast: Diese 9 Punkte sind genau der Inhalt für eine **Agentur** — siehe
> `dropship/AGENTUR-BRIEFING.md`. Mit dieser Liste kann eine Agentur in 1–2 Tagen den „professionellen Look“ umsetzen.
