## 🥉 C) E-Mail — Willkommens-Flow (Klaviyo, verbunden)

Das WELCOME10-Popup sammelt jetzt E-Mails in Klaviyo (Liste „Newsletter Subscribers", ID T2VHfu).
**Willkommens-Mail-Vorlage ist erstellt:** „LuxeStyle – Willkommen (WELCOME10)" (Template-ID T7bFP4)
— Branding, WELCOME10-Code, Sommer-CTA, Abmeldelink.

**Dein 1× Setup (Klaviyo, ~5 Min) — Flow aktivieren:**
1. Klaviyo → **Flows** → **Create Flow** → Vorlage **„Welcome Series"** (oder leerer Flow).
2. **Trigger:** „When someone subscribes to a list" → Liste **Newsletter Subscribers**.
3. **Email-Schritt** hinzufügen → Template **„LuxeStyle – Willkommen (WELCOME10)"** (T7bFP4) wählen.
4. Betreff: **„Willkommen 💛 Hier sind deine 10%"** · Absender: LuxeStyle CH.
5. (Optional) Tag 3: Erinnerungs-Mail „Dein Code läuft bald ab".
6. **Live schalten.**

**Später (kostenlos, hoher ROI):**
- **Abandoned-Cart-Flow** (Trigger „Checkout started", nach 1h + 24h) — holt verlorene Warenkörbe zurück.
- **Monatlicher Newsletter** an alle Subscriber (neue Produkte, Saison-Looks).
