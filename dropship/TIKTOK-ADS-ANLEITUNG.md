# 🎯 TikTok-Ads — Anleitung (LuxeStyle, Stand 2026-06-03)

## Empfehlung: NICHT die alte Kampagne reparieren → EINE neue, saubere Conversion-Kampagne
Die alte „LuxeStyle Mode CH – Sommer" hatte eine **abgelehnte/pausierte Anzeigengruppe**
(„Änderung nicht genehmigt") und lieferte nie aus; dazu kamen weltweite Auto-/Smart-Kampagnen
(Junk-Traffic). Reparieren lohnt nicht. **Mach es neu — aber bewusst nur EINE saubere Kampagne**,
alles andere AUS. (Nicht „alles neu" im Sinne von Shop/Pixel — der steht; nur die Kampagne neu.)

## Schritt 0 — Aufräumen (zwingend, sonst Geld-Leck)
- TikTok Ads Manager → **Kampagnen**: ALLE laufenden Auto-/Smart-/Reichweite-/Traffic-/Video-Views-
  Kampagnen **pausieren**.
- TikTok-**Shopify-App** → „Smart Performance / automatische Kampagnen" **deaktivieren**
  (erstellt sonst wieder weltweite Auto-Kampagnen).

## Schritt 1 — Kampagne
- **Create → Ziel: Conversions / Sales** (NICHT Reach, NICHT Traffic, NICHT Video Views).
- Name: „LuxeStyle CH – Sommer Conversions 06".

## Schritt 2 — Anzeigengruppe (Ad Group)
- **Pixel:** `D8EKVR3C77U6KT5BTBD0` (der Shopify-verbundene — NICHT D8EQE4/D85BAG).
- **Optimization Event:**
  - **Start: „Add to Cart"** (der Pixel hat noch ~0 Kauf-Events zum Lernen).
  - **Nach ~20–30 ATC-Events → auf „Complete Payment / Kauf"** umstellen.
- **Placement:** nur **TikTok** (Pangle/andere aus).
- **Standort:** Schweiz · **Sprache:** Deutsch + Französisch.
- **Geschlecht:** Frauen · **Alter:** 18–34.
- Interessen (optional): Mode, Damenbekleidung, Sommerkleider, Online-Shopping.
- **Budget:** 20 CHF/Tag. **3–4 Tage durchlaufen lassen** (Lernphase nicht täglich anfassen!).

## Schritt 3 — Ads / Creatives
- **Diese 4 Reels hochladen** (von mir geschickt, alle 9:16 / 1080×1920, Hook in Sek. 1):
  `eleganz.mp4` · `sommer.mp4` · `premium.mp4` · `auto-20260603-1456.mp4` (Themen-Mix).
- **Landing-URL:** `https://luxestyle.ch/collections/sommer`
- **CTA:** „Jetzt shoppen".
- Policy: kein „Vorher/Nachher", keine unrealistischen Versprechen, kein Preis im Video → sonst Ablehnung.
- Tipp: 3–4 Ads in EINER Ad Group = TikTok testet automatisch das beste Creative.

## Schritt 4 — Nach 2–3 Tagen
Schreib mir **„Auswertung"** → ich prüfe per ShopifyQL: Sessions, **Add-to-Cart-Rate** (Ziel >2–3 %),
Checkouts, Käufe, Traffic-Qualität. Erwartung bei richtigem Conversion-Traffic: ATC springt von ~0 % hoch,
erste Käufe.

## Warum das der Haupthebel ist
Shop ist verkaufsbereit (Add-to-Cart live getestet, Pixel grün, Funnel komplett). Das 0-Käufe-Problem
ist **Traffic-Qualität**, nicht der Shop. Nur eine auf KÄUFE optimierte Kampagne dreht das. Die organischen
Gratis-Reels (4h-Autopost) laufen parallel als Reichweiten-Zusatz.
