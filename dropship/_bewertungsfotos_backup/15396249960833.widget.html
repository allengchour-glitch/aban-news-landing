Royce Hills

Absolute home run. This 36mm 316l stainless piece features a stunning sunray blue dial, sapphire glass, a crisp screw-down crown, and a beautiful polished center executive bracelet with a milled butterfly clasp. Out of the box, it comfortably fits my 9" wrist with zero pins removed—i just shifted 3 links to the long side for a perfect balance.

​ The factory sunon sp28 provides a beautiful mechanical sweep seconds, so i am leaving it in for now. However, the dial feet position confirms this platform is 100% compatible with a miyota 2350. Having already executed this exact drop-in swap on my white version, i can verify it is a seamless mechanical upgrade path. My only minute qc observation is a microscopically misaligned date bubble, but it is so slight that no one else would ever notice. High-tier value for watch builders!
