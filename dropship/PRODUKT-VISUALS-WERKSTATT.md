# Produkt-Visuals-Werkstatt — Fotos & Videos selber machen

**Für wen:** 1 Person, nur Smartphone + Gratis-/Billig-Tools, kein Studio. Markt Schweiz (LuxeStyle).
**Eiserne Regel:** Das Produkt bleibt **echt** wie geliefert — Form, Farbe, Material, Label, Proportionen. KI/Edit darf nur **reinigen, freistellen, Hintergrund/Licht** ändern, **nie das Produkt erfinden oder verfälschen**. Kein Voiceover, On-Screen-Text statt Stimme, Musik = `automation/music/luxe-premium.wav`.

> **Querverweis (nicht duplizieren):** Hook/Skript/Caption-Strategie, KI-Image-to-Video und Paid-Ads-Readiness stehen in `dropship/SUPER-VIDEO-PLAYBOOK.md`, `dropship/VIDEO-KI-PIPELINE-VORBEREITUNG.md` und `dropship/VIDEO-ADS-PAID-READINESS.md`. **Dieser Guide = nur das Produktions-Handwerk** (wie entstehen die Fotos/Clips physisch).

> **Ehrliche Grundregel zur Priorisierung:** Eigene Handyfotos/-Clips gibt es **nur für Produkte, die physisch vorliegen**. Wo nur CJ-Lieferantenfotos da sind → siehe TEIL C (produkttreuer Still-zu-Content-Weg). Nichts fotografieren, was nicht da ist; nichts KI-faken.

## TEIL A — Produktfotos

### A1. Handy-Foto-Setup (gratis, der eigentliche Hebel)

Der Unterschied liegt **nicht** am Equipment, sondern an **weichem Seitenlicht + sauberem Hintergrund + Stativ**.

- [ ] **Licht-Basis:** Tisch **seitlich** ans grosse Fenster (ca. 90° versetzt), Licht kommt von der Seite — niemals Produkt zwischen Fenster und Kamera (sonst Silhouette). Je näher am Fenster, desto weicher.
- [ ] **Harte Sonne diffundieren:** dünnes weisses Bettlaken / Backpapier / Duschvorhang vors Fenster. Bewölkter Tag ist ideal.
- [ ] **Aufhellen gratis:** gegenüber dem Fenster eine **weisse Pappe / Schaumstoffplatte / Alufolie** aufstellen — wirft Licht in die Schatten zurück, ersetzt die zweite Lampe.
- [ ] **Hintergrund:** glatte weisse/hellgraue/beige Fläche; Gratis-Sweep = grosse Pappe/Tonpapierrolle von der Wand auf den Tisch biegen (keine sichtbare Kante).
- [ ] **Kamera-Settings:** immer **Rückkamera**, **kein Digitalzoom** (näher rangehen statt zoomen), ISO niedrig (100–200), höchste JPG-Qualität oder **ProRAW** (iPhone Pro: Einstellungen → Kamera → Formate → Apple ProRAW). Weissabgleich meist Auto; bei Gelbstich weisse Pappe als Referenz mitfotografieren.
- [ ] **Stativ + Fokus locken:** Mini-/Tischstativ → scharf + immer gleiche Höhe/Distanz = einheitlicher Katalog. Auf das Detail tippen bis **AE/AF-Lock**, dann springt Fokus/Belichtung zwischen Aufnahmen nicht.

**Mode (Flat-Lay & hängend):**
- [ ] Vor dem Shoot **dämpfen/bügeln**, Fusselrolle, lose Fäden abschneiden (Falten/Fussel = wirkt billig = kostet Käufe).
- [ ] Flat-Lay: sauber auslegen, Handy **parallel zum Boden** von oben. Funktioniert besonders gut für Accessoires/Herrenmode.
- [ ] Hängend: Bügel an Wand oder unsichtbare Schnur; Schneiderpuppe + Haken später wegretuschieren.
- [ ] **Immer mehrere Winkel:** Vorder-, Rück-, Seite + Detail-Nahaufnahmen (Stoff, Naht, Knopf, Etikett) — Details verkaufen Qualität.

**Schmuck (Kernproblem = Reflexionen):**
- [ ] **DIY-Lichtzelt:** weisses Backpapier/Tracing-Paper/Duschvorhang als Box ums Stück, Fensterlicht seitlich durch — Metall spiegelt dann nur weisse Flächen.
- [ ] **Linsen-Loch-Trick:** Loch in weisse Pappe schneiden, Handy-Linse durchstecken → im glänzenden Metall spiegelt sich Pappe statt Telefon/Person.
- [ ] **Flags:** schwarze Pappe/Schaumstoff seitlich → schluckt störende Lichtstreifen, definiert Kanten.
- [ ] **Winkel:** Licht im 45°-Winkel oder höher (nicht frontal), leicht schräg fotografieren → lenkt Reflexe von der Linse weg.
- [ ] **Sauberkeit:** mit Mikrofasertuch polieren, Baumwollhandschuhe (Fingerabdruck = Reshoot), matte Unterlage (Velours/mattes Papier).
- [ ] **Makro-Schärfe:** Stativ, kein Digitalzoom, ggf. Makro-Vorsatzlinse; manueller Fokus, für Maximum App **Halide** (Focus-Peaking + RAW).

### A2. KI-Aufwertung (produkttreu)

- [ ] **Freistellen / weisser Hintergrund:** Shopify Media Editor (gratis), remove.bg oder Photoroom.
- [ ] **Lifestyle-Szene:** Freisteller in Photoroom/Pebblely in eine Szene setzen (Marmor, Sommer, Stoff). **Regel:** nur Umgebung generieren, das **Original-Produkt-PNG bleibt unverändert oben drauf**.
- [ ] **Upscale/Entrauschen:** Krea Enhance oder Upscale.media (gratis, ohne Wasserzeichen), 2×–4× — nur Schärfen der Vorlage, kein Inhaltsumbau.
- [ ] **Feinschliff:** Belichtung/Weissabgleich/Schärfe in Snapseed (gratis); dezenter Schlagschatten unter dem Produkt für Tiefe.
- [ ] **Wasserzeichen-/Lizenz-Check:** Photoroom-Free setzt Wasserzeichen + ist nicht-kommerziell; für Shop/Ads wasserzeichenfreien Export (Pro) oder Gratis-Tool ohne Watermark nutzen.

## TEIL B — Produktvideos

### B1. Handy-Dreh (B-Roll, Stabilisierung, Licht)

- [ ] **Kamera einmalig einstellen:** 4K/**60fps** für normale Clips (Spielraum zum Verlangsamen), Slo-mo separat **120/240fps**, **HDR-Video AUS** (sonst dunkel/ausgewaschen in CapCut/VN), Raster an, AE/AF-Lock aufs Produkt.
- [ ] **Licht:** seitlich am Fenster, Gardine/Backpapier als Diffusor. Glanzteile/Schmuck → **LED-Panel oder Lichtzelt statt Ringlicht** (Ringlicht hinterlässt sichtbaren Kreis-Reflex im Metall).
- [ ] **Stabilisierung:** Try-on + langsame Schwenks = Mini-Stativ + eingebaute Stabi reicht. Für flüssige Bewegungs-Shots Gimbal (DJI Osmo Mobile 8 / Insta360 Flow 2 Pro). **Makro/Schmuck IMMER Stativ + 2-Sek-Timer/Bluetooth-Auslöser** (jede Erschütterung ruiniert die Nahaufnahme).
- [ ] **Shot-Liste pro Produkt (60 s drehen → 5–6 Clips):**
  1. Detail/Makro langsam heranfahren (Verschluss, Naht, Stein, Material)
  2. Bewegung (Stoff fallen lassen, Kette schwingen, Tasche öffnen, 360°-Dreh)
  3. Lifestyle/Try-on am Körper (zeigt Grösse + Fall)
  4. Flat-Lay von oben (Produkt + 1–2 Props)
  5. Slo-mo-Hero (Haar/Stoff/Glitzer in 120–240fps)
  - Jeden Shot **5–8 Sek** halten, mit etwas Bewegung an Anfang/Ende (für saubere Cuts).
- [ ] **Mehr aus wenig:** dieselben Teile in verschiedenen Brennweiten (weit/mittel/makro) und Tempi (normal/slow) → aus 3–4 Produkten genug für eine Woche Reels.

### B2. Schnitt / Edit

- [ ] **Editor:** **VN Video Editor** (gratis, kein Wasserzeichen, Auto-Untertitel) oder **InShot Pro** (~20 CHF/Jahr). CapCut nur bewusst (Pro teuer ~20 USD/Monat, ToS seit 2025 umstritten). Am Laptop: DaVinci Resolve (gratis).
- [ ] **Format:** **9:16 / 1080×1920** vertikal.
- [ ] **Musik:** `automation/music/luxe-premium.wav` leise als Bett, **harte Cuts auf den Beat**. Keine CapCut-Trendsounds (Copyright + Marken-Inkonsistenz).
- [ ] **Text statt Stimme:** ~80 % schauen stumm → On-Screen-Text (Produktname + Preisanker/Vorteil), gross + kurz, lesbar in <2 Sek. Auto-Captions wo Sprache fehlt nicht nötig — Textlabels reichen.
- [ ] **Hook:** stärkster Shot in **Sekunde 1–2** (Daumenstopp). Gesamtlänge 15–30 Sek.
- [ ] **Ruhig schneiden:** weiche Fades, keine ruckartigen Auto-Transitions/Zoom-Sprünge („nicht wackeln"-Regel).
- [ ] **QA auf dem Handy** (nicht am grossen Schirm): kein Fenster-/Ringlicht-Reflex im Produkt, kein Wackeln, Text lesbar.

## TEIL C — Nur Lieferantenfotos (kein Muster da)?

**Ehrlich:** Echtes B-Roll ist dann unmöglich; Still-Slideshows konvertieren schwächer als echtes UGC/Bewegung. Das ist eine **Brücke**, bis pro Bestseller 1–2 eigene Handy-Clips existieren. Und es gibt eine **Rechtsfalle**.

- [ ] **Rechts-Check ZUERST:** CJ-Katalogbilder sind IP von CJ/Lieferant; das User-Agreement gewährt **kein ausdrückliches Marketing-/Social-Ad-Recht** (nur Verkauf der Produkte). Reine **Shop-Listings** sind praktisch geduldet; für **TikTok/Pinterest-Ads** ist eigenes Material oder CJ-Freigabe / CJ-Shooting-Service mit Nutzungsrecht sicherer.
- [ ] **Sortieren:** nur saubere Stills ohne fremde Logos/Wasserzeichen/**fremde Gesichter** (Persönlichkeitsrecht) verwenden.
- [ ] **Upscalen:** Krea Enhance / Upscale.media (gratis) 2×–4× — produkttreu.
- [ ] **Lifestyle-Hintergrund:** Freisteller (remove.bg/Photoroom) in generierte Szene (Photoroom/Pebblely) — **nur Hintergrund, Produkt-PNG bleibt original**.
- [ ] **Slideshow-Video (Kern-Workflow, gratis):** 5–8 Stills in CapCut/VN, je 2–4 Sek, **Ken-Burns** (langsamer Zoom/Pan) + weiche Crossfades, 1080×1920. On-Screen-Text (Hook Sek 1–2 → 1 Benefit/Bild → Preisanker → CTA). Musik = luxe-premium.wav. 15–30 Sek.
- [ ] **Pinterest/Bild-Posts:** in Canva 1080×1350-Pins — Detail-Collage, Trust-Band (Gratis-Versand ab CHF 65, WELCOME10). Pinterest = evergreen + kaufabsicht-stark.
- [ ] **Optional KI-Bewegung (vorsichtig):** ein starkes Still mit Kling AI (~66 Credits/Tag) oder Hailuo (200 Start-Credits) animieren — **nur subtile Kamerafahrt, keine Produktänderung**. Gratis = Wasserzeichen → für finale Ads wegcroppen/Bezahl-Export oder lieber eigenes Material.
- [ ] **Stärkster Hebel:** sobald ein Hero läuft → **Muster bestellen**, 10–20 Sek eigene Handy-Clips (Auspacken/Tragen/Detail). 100 % rechtssicher, konvertiert messbar besser.

## Solo-Batch-Routine (Wochenplan)

Engpass ist die **Wiederholbarkeit**, nicht das Einzelbild. Einmal **Brand Kit + Vorlagen** bauen, dann pro Produkt in Minuten durchschicken.

**Einmalig (1×, dann nie wieder):**
- [ ] Canva Brand Kit: LuxeStyle-Farben (Hex notieren), Font-Paar, Logo, feste Bausteine (Preis-Anker, „Gratis-Versand ab CHF 65", WELCOME10).
- [ ] 3–4 Bild-Vorlagen (1:1 weiss, 4:5 mit Preisband, Lifestyle-Slot) mit Bild-Frames.
- [ ] 1–2 Video-Vorlagen (8–15 s, 3–4 Foto-Slots, Textfelder, luxe-premium.wav fest hinterlegt, kein Voiceover).

**Fester Wochenblock (Ziel 5–8 Produkte):**
- [ ] 30–60 min Rohmaterial sammeln + benennen → `produkt_farbe_winkel_datum.jpg`, Ordner nach Monat/Kollektion.
- [ ] 30–60 min freistellen/veredeln im Stapel (Photoroom/Pixelcut) — nur reinigen, Form/Label/Material exakt lassen.
- [ ] 30 min Bilder per Vorlage füllen: Canva **Bulk Create** (CSV: Name/Preis/Bilddatei → ein Klick alle Designs; nur Pro/Desktop, max. 300 Zeilen). Ohne Pro: Vorlage duplizieren, Fotos manuell tauschen.
- [ ] 30–60 min Videos: Vorlage duplizieren, 3–4 Bilder + Text rein, exportieren 1080×1920. Ruhige Fades, kein Zoom-Sprung.
- [ ] Mid-Session kurz auf grösserem Screen prüfen → Fehler früh fangen.
- [ ] Archivieren: `/fertig/<monat>/`, Originale behalten, 3-2-1-Backup (Drive + lokal).

**Pro Produkt = Mindest-Set:** 1 Slideshow/Video + 1–2 Bilder/Pins.

## Verbote (hart)

- [ ] **Produkt NIE verfälschen.** KI/Upscaler/Szenen-Tools dürfen nur Hintergrund/Licht/Schärfe ändern — Form, Farbe, Label-Text, Material, Proportionen bleiben wie geliefert. KI das Produkt neu generieren lassen = Retouren + Werbe-/Markenverstoss.
- [ ] **Kein Voiceover.** Immer On-Screen-Text + `luxe-premium.wav`.
- [ ] **Keine CapCut-/App-Trendsounds** (Copyright + Marken-Inkonsistenz). Nur die eigene Lizenzmusik.
- [ ] **Kein `%`-Zeichen im drawtext** (ffmpeg interpretiert `%` als Format-Token → bricht/zeigt Müll). „10%" als „10 Prozent" oder „-10" schreiben.
- [ ] **Keine Emojis im drawtext** (ffmpeg/Schriftart rendert sie als Tofu-Kästchen). Emojis nur in Caption/Post-Text, nie im gebrannten Video-Text.
- [ ] **Kein TikTok-Wasserzeichen auf IG/anderen Kanälen.** Clips ohne TikTok-Logo exportieren/croppen, sonst Reichweiten-Strafe + billiger Look.
- [ ] **Kein „CJ"-Leak.** Kein Lieferantenname/-Logo, kein „CJ Neuheiten", kein fremdes Wasserzeichen, keine fremden Models/Gesichter in Ad-Material.
- [ ] **Kein Digitalzoom**, **kein Gegenlicht**, **kein ungebügeltes/verfusseltes** Mode-Foto, **kein Auto-Modus** ohne AE/AF-Lock (uneinheitlicher Katalog).
- [ ] **Keine fehlenden Produkte „fotografieren".** Nur physisch vorhandene Ware eigen ablichten; sonst TEIL C.
