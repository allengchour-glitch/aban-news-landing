Escape a JSON string

Turn text into a valid JSON string — line breaks, tabs, quotes and backslashes are escaped correctly (\n \t \" \\) — or turn a JSON string back into plain text. Everything local in your browser, nothing is sent.

Result

Escaping produces a value you can drop straight into JSON or code. Unescaping turns a JSON string (with or without surrounding ") back into plain text — including \uXXXX. If the input is not a valid JSON string, a hint appears. Everything local, no upload.
