Build a type scale

A harmonious font-size scale from a base size and a ratio — the foundation of every good type system. You get px and rem values and ready-made CSS variables to copy. Everything runs locally in your browser, nothing is sent.

CSS variables 

    
Each step = base size × ratio^step. Step 0 is the base size (body text). rem refers to the 16 px browser default. Tip: smaller ratios (1.125–1.25) for text-heavy pages, larger ones (1.5–1.618) for expressive headlines. All local, no upload.
