JSON ↔ CSV umwandeln

Ein JSON-Array von Objekten in eine CSV-Tabelle umwandeln — oder umgekehrt. Mit korrektem Anführungszeichen-Escaping (RFC 4180), wählbarem Trennzeichen, Kopieren und Download. Alles lokal im Browser, nichts wird gesendet.

Ergebnis

JSON → CSV erwartet ein Array von Objekten; die Spalten sind die Vereinigung aller Schlüssel. Verschachtelte Werte werden als JSON-Text in die Zelle geschrieben. CSV → JSON nimmt die erste Zeile als Spaltenüberschriften. Alles lokal, kein Upload.
