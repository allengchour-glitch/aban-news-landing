JSON-String escapen

Text in einen gültigen JSON-String umwandeln — Zeilenumbrüche, Tabs, Anführungszeichen und Backslashes werden korrekt escaped (\n \t \" \\) — oder einen JSON-String wieder in Klartext zurückverwandeln. Alles lokal im Browser, nichts wird gesendet.

Ergebnis

Beim Escapen entsteht ein Wert, den du direkt in JSON oder Code einsetzen kannst. Beim Unescapen wird ein JSON-String (mit oder ohne umschließende ") zu Klartext — inklusive \uXXXX. Ist die Eingabe kein gültiger JSON-String, erscheint ein Hinweis. Alles lokal, kein Upload.
