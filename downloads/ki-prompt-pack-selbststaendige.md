# KI-Prompt-Pack für Selbstständige

**von aban news – abannews.com**

30 sofort nutzbare deutsche KI-Prompts für deinen Geschäftsalltag — Kundengewinnung, Angebote, Social Media, E-Mails, Website, Produkttexte und Buchhaltung verständlich erklärt.

---

## So nutzt du das Pack (ehrlich, ohne Hype)

- Kopiere einen Prompt in dein KI-Tool (ChatGPT, Claude, Gemini o. ä.).
- Ersetze alle Platzhalter `[in eckigen Klammern]` durch deine echten Angaben. Je konkreter, desto besser das Ergebnis.
- KI liefert einen **Entwurf**, keine fertige Wahrheit. Lies alles gegen, prüfe Zahlen, Fakten und rechtliche Aussagen selbst.
- Bei sensiblen Themen (Steuern, Recht, Verträge) ist KI nur ein Erklär- und Sortier-Werkzeug — die Verantwortung bleibt bei dir bzw. deiner Beraterin/deinem Berater.
- Gib keine echten Kundendaten, Passwörter oder Geschäftsgeheimnisse ein, die nicht raus dürfen.

## 1. Kundengewinnung

### 1.1 Wunschkunden-Profil
```
Ich bin [Beruf/Branche] und biete [Leistung/Produkt] in [Region] an.
Erstelle ein Profil meines idealen Kunden: typische Person oder Firma,
Hauptprobleme, Auslöser für einen Kauf und 3 Orte, wo ich sie erreiche.
```
*Wofür: Klarheit, wen du ansprechen willst, bevor du Werbung machst.*

### 1.2 Kalt-Akquise-Nachricht
```
Schreibe eine kurze, höfliche Erstkontakt-Nachricht (max. 6 Sätze) an
[Zielkunde], um [Leistung] anzubieten. Kein Druck, ein klarer Mehrwert,
eine einfache Rückfrage am Ende. Ton: [seriös / locker].
```
*Wofür: Neue Kontakte ansprechen, ohne aufdringlich zu wirken.*

### 1.3 Elevator-Pitch
```
Formuliere 3 Varianten eines 2-Satz-Pitches für [mein Angebot].
Zielgruppe: [Zielgruppe]. Nutzen klar in den ersten 8 Wörtern.
Varianten: 1) sachlich, 2) Nutzen-fokussiert, 3) mit kleiner Story.
```
*Wofür: Auf die Frage "Was machst du eigentlich?" überzeugend antworten.*

### 1.4 Empfehlungs-Anfrage
```
Schreibe eine freundliche Nachricht an zufriedene Bestandskunden, in der
ich um eine Weiterempfehlung oder Bewertung für [Leistung] bitte.
Dankbar, kurz, ohne Betteln. Ton: [persönlich].
```
*Wofür: Mehr Aufträge über Empfehlungen statt teurer Werbung.*

### 1.5 Angebots-Follow-up
```
Ich habe [Kunde] vor [X Tagen] ein Angebot über [Leistung] geschickt,
noch keine Antwort. Schreibe eine nette Erinnerung, die nicht drängt,
aber eine klare nächste Aktion vorschlägt.
```
*Wofür: Liegengebliebene Angebote höflich nachfassen.*

## 2. Angebote & Rechnungen (Texte)

### 2.1 Angebotstext
```
Erstelle einen klaren Angebotstext für [Leistung] an [Kunde].
Enthalten: kurze Einleitung, Leistungsbeschreibung in Stichpunkten,
Preis [Betrag], Zahlungs- und Lieferbedingungen, freundlicher Abschluss.
Ton: professionell, verständlich.
```
*Wofür: In Minuten ein sauberes Angebot formulieren.*

### 2.2 Leistungsbeschreibung für die Rechnung
```
Formuliere eine präzise Leistungsbeschreibung für eine Rechnung über:
[was wurde gemacht]. Maximal 2 Sätze, sachlich, für die Buchhaltung
nachvollziehbar.
```
*Wofür: Verständliche Rechnungspositionen statt kryptischer Stichworte.*

### 2.3 Zahlungserinnerung (freundlich)
```
Schreibe eine erste, freundliche Zahlungserinnerung für Rechnung
[Nummer] über [Betrag], fällig seit [Datum]. Ton: verständnisvoll,
Annahme: vergessen, nicht böse Absicht. Mit neuer Zahlungsfrist.
```
*Wofür: Offene Rechnungen einfordern, ohne die Beziehung zu belasten.*

### 2.4 Letzte Mahnung
```
Formuliere eine bestimmte, aber sachliche letzte Mahnung für Rechnung
[Nummer] über [Betrag]. Klare Frist [Datum] und Hinweis auf weitere
Schritte. Höflich im Ton, eindeutig in der Sache.
```
*Wofür: Den letzten schriftlichen Schritt vor weiteren Maßnahmen.*

### 2.5 Preiserhöhung ankündigen
```
Schreibe eine Nachricht an Bestandskunden, die eine Preisanpassung von
[alt] auf [neu] ab [Datum] ankündigt. Begründung: [Grund]. Wertschätzend,
ehrlich, ohne Entschuldigungston.
```
*Wofür: Preise anheben und Kunden trotzdem mitnehmen.*

## 3. Social Media

### 3.1 Wochen-Postingplan
```
Erstelle einen Posting-Plan für 1 Woche (5 Posts) für [Plattform] zu
[Thema/Branche]. Pro Post: Idee, Hook, kurzer Text und ein Call-to-Action.
Mische: Tipp, Einblick hinter die Kulissen, Kundenbeispiel, Frage, Angebot.
```
*Wofür: Eine Woche Content in einem Rutsch planen.*

### 3.2 Einzelner Post
```
Schreibe einen [Plattform]-Post über [Thema]. Starker erster Satz,
einfacher Sprachstil, ein konkreter Tipp, am Ende eine Frage an die
Leser. Länge: [kurz / mittel]. Ton: [locker / fachlich].
```
*Wofür: Schnell einen guten Einzelpost erstellen.*

### 3.3 Reel-/Video-Skript
```
Schreibe ein 30-Sekunden-Skript für ein kurzes Video über [Thema].
Aufbau: Hook (3 Sek.), 3 knappe Punkte, Abschluss mit Aufforderung.
On-Screen-Text in Stichworten. Zielgruppe: [Zielgruppe].
```
*Wofür: Kurzvideos vorbereiten, ohne lange zu grübeln.*

### 3.4 Hashtags & Caption
```
Erstelle 3 Caption-Varianten und 10 passende Hashtags (gemischt aus
groß und nischig) für einen Post über [Thema] auf [Plattform].
Keine übertriebenen Versprechen.
```
*Wofür: Reichweite erhöhen, ohne Spam-Hashtags.*

### 3.5 Aus altem Inhalt Neues machen
```
Hier ist ein bestehender Text/Blogartikel: [Text einfügen].
Mache daraus 3 Social-Media-Posts mit unterschiedlichem Blickwinkel
für [Plattform]. Jeweils mit Hook und Call-to-Action.
```
*Wofür: Vorhandene Inhalte mehrfach nutzen statt immer neu schreiben.*

## 4. E-Mails

### 4.1 Erstantwort auf eine Anfrage
```
Ein Interessent fragt nach [Leistung]. Schreibe eine freundliche
Erstantwort: bedanken, 1-2 Rückfragen zur Klärung, nächster Schritt
(z. B. kurzes Telefonat). Ton: zugewandt, professionell.
```
*Wofür: Schnell und sympathisch auf Anfragen reagieren.*

### 4.2 Newsletter
```
Schreibe einen kurzen Newsletter für [Zielgruppe] zum Thema [Thema].
Aufbau: Betreffzeile (max. 50 Zeichen), persönlicher Einstieg, ein
nützlicher Tipp, ein dezenter Hinweis auf [Angebot], Abschluss.
```
*Wofür: Kontakt zu deiner Liste halten, ohne werblich zu wirken.*

### 4.3 Betreffzeilen testen
```
Erstelle 8 Betreffzeilen für eine E-Mail über [Inhalt]. Mische:
neugierig, nutzenorientiert, mit Zahl, mit Frage. Max. 50 Zeichen,
keine Clickbait-Übertreibung.
```
*Wofür: Höhere Öffnungsraten durch bessere Betreffzeilen.*

### 4.4 Schwierige E-Mail (Reklamation)
```
Ein Kunde beschwert sich über [Problem]. Schreibe eine ruhige,
lösungsorientierte Antwort: Verständnis zeigen, Sachverhalt klären,
konkreten Lösungsvorschlag machen. Ton: sachlich, deeskalierend.
```
*Wofür: Konflikte schriftlich entschärfen statt verschärfen.*

### 4.5 Absage formulieren
```
Ich muss [Anfrage/Auftrag] absagen, Grund: [Grund]. Schreibe eine
höfliche Absage, die wertschätzend bleibt und – wenn möglich – eine
Alternative oder Empfehlung anbietet.
```
*Wofür: Nein sagen, ohne die Beziehung zu zerstören.*

## 5. Website-Texte

### 5.1 Startseiten-Headline
```
Erstelle 5 Varianten einer Startseiten-Überschrift für [Angebot],
Zielgruppe [Zielgruppe]. Klarer Nutzen, max. 12 Wörter, kein Floskel-Deutsch.
```
*Wofür: Besucher in den ersten Sekunden abholen.*

### 5.2 Über-mich / Über-uns-Text
```
Schreibe einen Über-mich-Text (ca. 120 Wörter) für [Name/Beruf].
Inhalt: was ich mache, für wen, was mich auszeichnet, warum mir Kunden
vertrauen können. Persönlich, ehrlich, nicht prahlerisch.
```
*Wofür: Vertrauen aufbauen mit einer echten Geschichte.*

### 5.3 Leistungsseite
```
Erstelle den Text für eine Leistungsseite zu [Leistung]. Aufbau:
Problem des Kunden, meine Lösung, Ablauf in 3 Schritten, was inklusive
ist, Call-to-Action. Verständlich, ohne Fachjargon.
```
*Wofür: Eine Leistung so erklären, dass Kunden anfragen.*

### 5.4 FAQ-Block
```
Erstelle 8 häufige Fragen und kurze Antworten für die Website meiner
[Branche]. Themen: Ablauf, Preise, Dauer, Stornierung, Garantie.
Antworten ehrlich und konkret.
```
*Wofür: Rückfragen vorab klären und Einwände entkräften.*

### 5.5 Call-to-Action verbessern
```
Hier ist mein aktueller Button-/Aufruftext: [Text].
Schlage 5 stärkere Varianten vor, die zu [gewünschte Handlung] führen.
Aktiv, konkret, ohne Druck.
```
*Wofür: Mehr Klicks auf Anfrage- und Kauf-Buttons.*

## 6. Produktbeschreibungen

### 6.1 Verkaufsstarke Produktbeschreibung
```
Schreibe eine Produktbeschreibung für [Produkt]. Eigenschaften:
[Merkmale]. Wandle Merkmale in Nutzen um, Zielgruppe [Zielgruppe].
Aufbau: Aufhänger, Nutzen-Stichpunkte, kurzer Abschluss. Kein Hype.
```
*Wofür: Produkte beschreiben, die sich auch verkaufen.*

### 6.2 Kurzbeschreibung / Teaser
```
Erstelle eine Kurzbeschreibung (max. 2 Sätze) für [Produkt], die in
einer Übersicht oder Anzeige Lust auf mehr macht. Konkret, kein Geschwafel.
```
*Wofür: Knappe Texte für Listen, Shops und Anzeigen.*

### 6.3 Merkmale in Nutzen übersetzen
```
Hier sind die technischen Merkmale von [Produkt]: [Liste].
Formuliere zu jedem Merkmal den konkreten Vorteil für den Kunden
("Das bedeutet für dich: ...").
```
*Wofür: Aus trockenen Daten echte Kaufargumente machen.*

### 6.4 Produkttitel & SEO
```
Erstelle 5 suchmaschinenfreundliche Produkttitel für [Produkt] inkl.
wichtigster Suchbegriffe, plus eine Meta-Beschreibung (max. 155 Zeichen).
Natürlich formuliert, nicht mit Keywords überladen.
```
*Wofür: Bei Google und im Shop besser gefunden werden.*

## 7. Buchhaltung erklären lassen

> Hinweis: KI erklärt Begriffe verständlich, ersetzt aber **keine Steuer- oder Rechtsberatung**. Prüfe Aussagen mit deinem Steuerbüro oder offiziellen Quellen.

### 7.1 Begriff einfach erklärt
```
Erkläre mir den Begriff [z. B. Umsatzsteuer-Voranmeldung / EÜR /
Kleinunternehmerregelung] in einfachen Worten, als wäre ich
Einsteiger. Mit einem Alltagsbeispiel. Region: [DE / AT / CH].
```
*Wofür: Buchhaltungs-Fachbegriffe endlich verstehen.*

### 7.2 Ablauf in Schritten
```
Erkläre mir Schritt für Schritt, wie [z. B. eine Umsatzsteuer-
Voranmeldung / Reisekostenabrechnung] grundsätzlich abläuft.
Als Checkliste. Hinweis auf typische Fehler. Region: [DE / AT / CH].
```
*Wofür: Wiederkehrende Aufgaben strukturiert angehen.*

### 7.3 Fragen ans Steuerbüro vorbereiten
```
Ich habe einen Termin beim Steuerberater zum Thema [Thema].
Erstelle eine Liste mit 8 klugen Fragen, die ich stellen sollte,
und welche Unterlagen ich mitbringen sollte.
```
*Wofür: Beratungstermine effizient und vorbereitet nutzen.*

### 7.4 Belege sortieren – System
```
Schlage mir ein einfaches Ordnungssystem für meine Belege und
Rechnungen als [Soloselbstständige/r in Branche] vor: digital und
analog, monatliche Routine, Aufbewahrung. Praktisch und realistisch.
```
*Wofür: Belegchaos vermeiden, bevor es entsteht.*
