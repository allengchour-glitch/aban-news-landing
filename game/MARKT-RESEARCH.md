# 📊 Markt-Recherche — was Leute spielen wollen + was ein Spiel „super" macht (2026)

> Recherchiert für die Spielrichtung. Quellen: Steam-Wishlist-/Revenue-Analysen, Game-Feel/
> Retention-Artikel (Juni 2026). Ehrlich: der Markt ist stark skewed — **Top 10 % der Indies = ~84 %
> des Umsatzes.** Erfolg = richtiges Genre + echter Hook + Sichtbarkeit (Wishlist/Demo/Next Fest).

## Was Leute 2026 wollen (Genre-Nachfrage)
- **Höchster Median-Umsatz: Simulation, Strategie, ROGUELITE.** ← bestes Aufwand/Ertrag für Solo+KI.
- Starke Trends: **Roguellike-Deckbuilder**, Cozy/Life-Sim, Survival (Subnautica 2 = meist-gewünscht, 3,8 Mio),
  Narrative-Action, **Chaotic Co-op** (R.E.P.O., Peak — „laughs-per-minute", verbreitet sich viral über Streamer/Shorts).
- Plattform: **PC/Steam zuerst** (Wishlist + Demo + Steam Next Fest = Sichtbarkeit), dann Mobile/Web.

## Was ein Spiel „super"/süchtig macht (Design-Prinzipien)
1. **Sofort-Belohnung** (schnelle Erfolge) + **VARIABLE Belohnung** (unvorhersehbar, Slot-Machine-Effekt → „nur noch eine Runde").
2. **Flow:** Schwierigkeit wächst genau mit dem Können → nie zu leicht, nie unfair.
3. **Hook in der 1. Session:** in Minuten klar *was/wie/warum Spass*. Kein Tutorial-Wall.
4. **Tight Controls zuerst, Juice danach** — Feedback (Partikel/Sound/Screenshake) verstärkt, ersetzt aber nie saubere Steuerung (sonst „lügt" das Spiel).
5. **Viralität:** teilbarer Moment (Highscore-Share, lustiger Clip) → organische Reichweite statt bezahlter Werbung.
6. **Updates + Community** → Retention (sichtbar weiterentwickeln).

## ⇒ Entscheidung für unser Spiel (recherchiert)
**Neon Drift wird ein ROGUELITE** — das trifft alles oben:
- **Variable-Reward-Upgrades:** nach X Orbs eine **Wahl aus 3 zufälligen Upgrades** (Magnet, Schild, Slow-Mo,
  Doppel-Score, Phase, Tempo) → genau der süchtig machende „Slot-Machine"-Run-Aufbau.
- **Flow:** Tempo steigt; Upgrades halten den Run am Leben → „diesmal weiter".
- **Hook:** in 5 Sek verstanden (ausweichen + sammeln), Tiefe durch Build-Vielfalt.
- **Viral:** Highscore-/Run-Share (schon im Web-Prototyp angelegt).
- **Machbar Solo+KI:** Single-Player, kein Netcode (Chaotic-Co-op wäre viraler, aber Multiplayer-Netcode ist für uns zu teuer/riskant — bewusst NICHT).
