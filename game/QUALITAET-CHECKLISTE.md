## 🎮 Definition-of-Done (das ganze Spielerlebnis)
- [ ] **Start/Menü:** Titel, Play, Settings, sauberer Look (nicht „roher Prototyp").
- [ ] **Onboarding:** in 5 Sek verstanden, ohne Tutorial-Wall.
- [ ] **Core-Loop mit Juice:** Screenshake, Hit-Stop, Partikel, Trails, smooth Tweens — fühlt sich „saftig" an.
- [ ] **Progression:** Roguelite-Upgrades, Schwierigkeit steigt fair (Flow), Highscore/Unlocks.
- [ ] **Optik konsistent & pro:** eigenes Shader-/Post-Processing-Look (Bloom, Color-Grading), echte Modelle, ein klares Farbschema.
- [ ] **Audio komplett:** Musik (Loop) + alle SFX + dezente UI-Sounds.
- [ ] **UX:** Pause, Settings (Lautstärke/Grafik), Mobile-Steuerung, DE/EN.
- [ ] **Ende-Screens:** Game-Over, Score, Share, „nochmal" — befriedigend.
- [ ] **Performance:** stabile 60 fps (Mid-Range + Mobile), keine Ruckler/Leaks.
- [ ] **Bug-frei:** keine Fehler im Godot-Output, kein Crash über 10-Min-Session.
- [ ] **Store-fertig:** Steam-Seite, Trailer, 5+ Screenshots, Wishlist aktiv, KI-Kennzeichnung ausgefüllt.
