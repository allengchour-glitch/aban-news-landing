# Filter-Facetten einer neuen Seite verraten Datenfehler

Die neue Kollektion Weihnachtspullover zeigte im Filter «Haustierbedarf»: ein Damenpullover trug diesen Typ. Messung über die Kategorie Clothing fand 49 Kleidungsstücke mit fremdem Typ (Dessous als Spass-Elektronik, Jeansjacke als Werkzeug). Typ und Kategorie widersprechen sich in beide Richtungen (Denim-Tasche unter Clothing = Kategoriefehler); der Titel entscheidet.
