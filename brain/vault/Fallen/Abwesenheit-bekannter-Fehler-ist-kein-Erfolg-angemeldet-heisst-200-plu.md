# Abwesenheit bekannter Fehler ist kein Erfolg — angemeldet heisst 200 plus Handlung

Der Anmelde-Melder des Hetzner-Agenten meldete «ok» auf einer Cloudflare-Bot-Wand, «angemeldet: true» auf Googles Einwilligungswand mit Sign-in-Knopf, «ok» auf der deutschsprachigen Cloudflare-Seite (Musterliste nur englisch) und «angemeldet: true» auf cjdropshipping.com/404 (SPA antwortet 200 auf /404). Von vier «angemeldeten» Diensten hielt genau einer stand (Pinterest), weil nur dort eine Handlung gelang (Feld gelesen, geschrieben, neu geladen). Regel: jede Wache, die «alles gut» sagt, braucht Schichten mit verschiedenen Sinnesorganen (Ziel-Host, Statuscode, Adressmuster, Seitentext in allen Sprachen), sagt null statt true wo sie es nicht weiss, und «angemeldet» hängt an Status 200 und einer gelungenen Handlung — nie an einer erreichten Adresse.
