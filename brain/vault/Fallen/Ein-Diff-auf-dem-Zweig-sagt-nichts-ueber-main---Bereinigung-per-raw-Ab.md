# Ein Diff auf dem Zweig sagt nichts ueber main - Bereinigung per raw-Abruf auf jedem Zweig nachmessen

GEMESSEN 22.09.2026: Bankinstitut und Kontoinhaber standen nach dem Entfernen auf unserem Zweig (5521d6ca8, 19:50Z) weiter LIVE auf main (Squash 178ddbf4e, 18.09. 20:46Z, anderer Zweig; raw-Abruf HTTP 200). Unser Journal sprach von '35 Minuten im Repo, nur noch in der Historie' - gemessen war nur der eigene Zweig. Dazu: git log -S mit einem deutschen Wort findet keine englische Zeile ('account holder'). Verwandte Klasse: ein Draft ohne Grund-Tag ist fuer jeden Rueckholer unbegruendet (12 Konnektor-Drafts vom 15.09., 4 Helme; Klingen-Revive kannte handklinge-kein-ch-versand nicht), ein Waechter ohne Starter ist ein Bericht (verlustbringer.py seit 15.09.), ein Stillstandszaehler zaehlt nur Ungestrichenes (Alter ist nicht Dringlichkeit), ein Lage-Vergleich sucht den Sachverhalt, nicht den Wortlaut (grep 'bounce' fand '4.4.1' nicht), Werkzeugnamen-Suche findet keine Eigenbauten (Popup custom_liquid_lxpopup), Journal-Zeilenverweise driften (Datum + Ueberschrift nennen). Regel: nach jeder Bereinigung vertraulicher Daten JEDEN Zweig, auf den gepusht wird, per raw-Abruf messen; Urheber per order.events{appTitle} bzw. product.events feststellen, nicht vermuten.
