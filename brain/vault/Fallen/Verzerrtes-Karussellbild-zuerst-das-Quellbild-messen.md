# Verzerrtes Karussellbild: zuerst das Quellbild messen

IG-Karussell zeigte eine gestauchte englische Infografik. Shopify-Bild 800x800, unser Generator hält das Seitenverhältnis — der Lieferant hatte eine hohe Infografik auf Quadrat gepresst.
