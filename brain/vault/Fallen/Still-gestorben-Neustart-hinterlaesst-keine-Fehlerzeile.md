# Still gestorben: Neustart hinterlässt keine Fehlerzeile

Tagesläufe sterben beim stündlichen Container-Neustart ohne Traceback; ein vor dem Lauf gesetzter Anspruch lässt den Tag als erledigt gelten. Nachholen über still_gestorben (letzte Schreibung vor Container-Start + keine FERTIG/PAUSE-Zeile), aber nur bei Jobs mit unbedingter Schlusszeile.
