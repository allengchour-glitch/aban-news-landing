# Test-Agentenprofil misst keine Sichtbarkeit

Shopify Global Catalog (UCP) mit dem öffentlichen Test-Agentenprofil fand luxestyle.ch bei 5 eindeutigen Titeln nicht; der Admin unter admin.shopify.com/agentic zeigte gleichzeitig CHF 155.62 aus 113 Besuchen in 30 Tagen über ChatGPT/Shop. Sichtbarkeit an der Plattform-Auswertung messen, eine Test-Probe ist kein Käufer im Markt.
