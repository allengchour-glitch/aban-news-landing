# Klasse erst zu, wenn alle Schreibformen eines Lecks geprüft sind

Lieferantencodes im Farbfeld kamen in drei Formen: reiner Code (QW121), Code + Leerzeichen + Farbe (646 Schwarz, 2350 Black), Code mit angeklebtem Wort (3237Dark Brown). Die Regel vom 09.10. deckte nur die erste; der Importer-Helfer nur Codes mit Grossbuchstaben vorn. 396 aktive blieben stehen. Folge: beim Schliessen einer Klasse die Schreibformen aufzählen und je eine Kanarie anlegen; Trockenlauf über alle Kandidaten (fand angeklebtes Wort, Mass als Code, zu breite Silber-Kennung 9xx).
