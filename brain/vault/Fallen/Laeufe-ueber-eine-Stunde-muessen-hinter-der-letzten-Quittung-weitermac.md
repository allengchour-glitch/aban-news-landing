# Läufe über eine Stunde müssen hinter der letzten Quittung weitermachen

versand_jenachland (QUELLE=live) fand 1'000 Kandidaten, kam bis ~750 und starb im stündlichen Container-Neustart — jeder Neustart begann vorne (Log dreimal «… 150/1000»). Der Schwanz der Liste wurde nie erreicht; 821 Produkte trugen den Block fünf Tage nach «FERTIG». Fix: Kandidatenliste rotiert hinter das zuletzt quittierte Produkt. Gilt für jeden Lauf, der länger als die Container-Lebenszeit braucht.


**Traegt der Skill `messgeraet-zuerst`** — dort gehoert die Regel hinein, damit sie
sich beim naechsten passenden Auftrag von selbst laedt.
