# Publish-Falle

Produkt-IDs zum Publizieren **immer aus der Antwort von `create-product` nehmen**, nie raten und
nie aus einer Liste ableiten. Eine falsche ID antwortet mit „Ressource existiert nicht".

Danach `publishablePublish` mit genau dieser ID in alle sechs Kanäle — siehe
[[Sechs-Publications]].
