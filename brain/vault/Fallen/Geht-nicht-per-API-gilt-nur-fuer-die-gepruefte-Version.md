# Geht nicht per API gilt nur für die geprüfte Version

Transitzeit je Versandtarif stand als Betreiber-Klick, weil DeliveryMethodDefinitionInput in 2026-01/2026-10 kein Feld hat. In Admin-API 'unstable' gibt es rateGroupsToUpdate.rateDefinitionsToUpdate.minTransitTime/maxTransitTime (Changelog 24.02.2026). Vor jedem 'nur im Admin' die Introspektion über 2026-10, 2027-01 und unstable laufen lassen und search_docs_chunks fragen.
