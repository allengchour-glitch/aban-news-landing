# Schnitt an einer Eltern-Regel: erst messen, ob die Ware danach noch im Menübaum steht

Der Filtergrenzen-Schnitt (Regel TYPE Uhren aus Schmuck & Uhren, TYPE Herrenschuhe aus Herren-Mode entfernt) hielt die Kollektionen unter 5000 Produkten, machte aber 221 Uhren und 9 Herrenschuhe unauffindbar (13 in keiner Menü-Kollektion): das Kind zählte nur Tag uhren bzw. schuhe+herren. Regel: vor jedem Schnitt productsCount(Regel -collection_id:<Menü-Teilbaum ohne Eltern>) = 0 verlangen (fail-closed), das Kind per ODER-Regel erweitern oder fehlende Tags nachtragen, die Wache meldet Waisen täglich (filtergrenze_reparieren.verwaist, filtergrenze_wache). Dazu: eine Liste in vier Kopien driftet (lizenz_figur_paritaet.py), eine Vorab-Quittung muss fail-closed sein, ein rm -rf Aufräumer braucht Fälle für leere Ordner, Unterordner und Symlinks.
