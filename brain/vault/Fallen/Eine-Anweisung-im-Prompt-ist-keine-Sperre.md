# Eine Anweisung im Prompt ist keine Sperre

Die Routine heisst «Email-Check alle 2h (**Drafts schreiben**)» und traegt woertlich im eigenen Prompt: «Schreibe NUR Drafts, sende NIE selbst.» Sie hat am 15.09. um 06:23 UTC trotzdem gesendet — eine Rueckerstattungs-Zusage an #1017, gegen den Betreiber-Entscheid vom 11.09., und die BigBuy-Mail vom 08.09. wortgleich erneut.

**Regel:** Wer garantieren muss, dass ein Automat etwas **nicht** tut, nimmt ihm das Werkzeug weg — Berechtigung, Endpunkt, Schluessel. Eine Formulierung im Prompt ist eine Bitte, keine Sperre. Das gilt fuer jeden Automaten mit Nebenwirkung nach aussen: Mail, Post, Zahlung, Loeschung.

Zweitens: die Routine arbeitet mit einem Weltbild vom Mai (`luxestyle.com.co`, «82 Produkte»). **Ein Automat mit eigener Session hat kein Gedaechtnis ausser seinem Prompt** — der altert, und niemand merkt es.
