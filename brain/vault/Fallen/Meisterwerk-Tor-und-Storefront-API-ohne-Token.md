# Meisterwerk-Tor und Storefront API ohne Token

Reels mit stehendem Einstieg (Bewegung 1. Sekunde < 3) werden nicht mehr gepostet; Preis-Waechter lesen nur die Caption, der Bildpreis kann veraltet sein. Die Shopify Storefront API liest ohne Token (myshopify-Domain) - Ersatz fuer fehlenden Admin-Token bei Kaufbar-Pruefungen.
