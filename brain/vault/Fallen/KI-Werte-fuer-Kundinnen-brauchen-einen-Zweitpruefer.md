# KI-Werte für Kundinnen brauchen einen Zweitprüfer

Harte Prüfung (Zahlen bleiben, Grundfarben bleiben, kein englisches Restwort) liess «Bean paste → Bohnenpaste» (gemeint Altrosa) und «90to140 → 90×140» (Bereich wurde Mass) durch — formal gültig, inhaltlich falsch. Ein Zweitprüfer aus einer ANDEREN Modellfamilie (Groq qwen neben gpt-oss) lehnte beide ab. Regel: was Kundinnen im Kaufbereich lesen, braucht zwei Urteile; abgelehnte Einträge nur dann als endgültig merken, wenn der Zweitprüfer sie verwarf (harte Regeln können sich ändern).
