# Ein Muster, das auf der gesunden Seite anschlägt, misst nichts

Messgerät für die Startseite: 40 Abrufe mit grep auf «Fehler aufgetreten» → 40/40 Fehlerseite. Der Kanarienvogel (dieselbe Suche auf der nachweislich gesunden Kollektion) schlug genauso an: der String ist ein Übersetzungstext des Geschenkkarten-Formulars und steht auf JEDER Seite des Shops. Mit dem richtigen Signal (Grösse: Fehlerseite ~17 KB, Startseite ~3,14 MB) stand es 15/15 gesund. Regel: jedes neue Messmuster zuerst auf einer bekannt gesunden Vergleichsseite laufen lassen; «40/40» ist wie «0» eine Aussage über das Messgerät, nicht über die Sache.
