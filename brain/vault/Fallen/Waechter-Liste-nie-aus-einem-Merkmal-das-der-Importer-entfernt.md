# Wächter-Liste nie aus einem Merkmal, das der Importer entfernt

Der Auswahl-Nachrüster las nur Produkte, deren Text eine Wahl verspricht. Der Importer macht Ein-Varianten-Texte aber wahlSicher (Versprechen weg) und baut Varianten nur für Mode-Gruppen → 320/452 Neuimporte mit einer Variante, CJ führt bei 30/40 mehrere, keiner kam auf die Liste. Fix: Aufseher misst jede Ein-Varianten-CJ-Ware der letzten 3 Tage am Bestand (CJ-Variantenzahl).
