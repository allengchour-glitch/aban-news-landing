# Positives Urteil braucht dieselbe Strenge wie ein negatives

2G-Prüfung 10.10.: BLE-Muster ohne vordere Wortgrenze traf «suitable/available» → 5 Geräte «bluetooth = ok» → Freigabe-Tag netz-geprueft → GPS-Kollektion ging mit einem Leitungssucher online. Ein falsches «ok» schaltet frei, ein falsches «nein» erzeugt nur einen Entwurf. Kürzel immer mit \b auf beiden Seiten; auto-veröffentlichte Kollektion braucht Rückweg (leer → offline).
