# Es gibt kein Anmeldefenster - das einzige E-Mail-Feld steht im Fuss

GEMESSEN 2026-09-13 an fuenf Live-Seiten von luxestyle.ch: ein Anmeldefenster existiert NICHT. Geladen werden nur zwei fremde Erweiterungen (Partnerprogramm, Judge.me) - kein shopify-forms, kein static.klaviyo.com/onsite/js/klaviyo.js, kein Privy/Omnisend/Justuno/OptiMonk. Das Gedaechtnis behauptet seit 01.06. WELCOME10-Popup (Shopify Forms) live - das stimmt nicht. Das einzige E-Mail-Feld ist das Theme-Formular im Fuss und steht bei 89,6 bis 99,2 Prozent der Seite; auf der Startseite hinter 7,18 von 7,24 Millionen Zeichen. Dazu steht der Rabattcode WELCOME10 im Klartext im Ankuendigungsband jeder Seite - wer den Code geschenkt bekommt, traegt dafuer keine Adresse ein. Das erklaert 3 Abonnenten bei 1498 Kundendatensaetzen vollstaendig. Reihenfolge: erst den Anreiz nicht mehr verschenken, dann ein Fenster bauen - dafuer fehlt SHOPIFY_CLI_THEME_TOKEN.
