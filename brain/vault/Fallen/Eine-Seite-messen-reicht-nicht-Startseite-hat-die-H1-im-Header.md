# Eine Seite messen reicht nicht: Startseite hat die H1 im Header

Auf luxestyle.ch steht die H1 (visually-hidden) im Header nur auf der Startseite. Der Cart-Drawer-h2 «Dein Warenkorb ist leer» stand deshalb auf Produkt- und Kollektionsseiten VOR der H1, auf der Startseite nicht. Überschriften-Reihenfolge immer je Seitentyp messen (Startseite, Produkt, Kollektion, Seite).


**Traegt der Skill `messgeraet-zuerst`** — dort gehoert die Regel hinein, damit sie
sich beim naechsten passenden Auftrag von selbst laedt.
