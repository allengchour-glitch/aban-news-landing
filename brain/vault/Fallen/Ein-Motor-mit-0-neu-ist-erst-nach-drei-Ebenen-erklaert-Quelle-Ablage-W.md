# Ein Motor mit 0 neu ist erst nach drei Ebenen erklaert: Quelle, Ablage, Werkzeug

Der Reel-Motor meldete wochenlang 0 neue Reels. Drei unabhaengige Ursachen, keine im Log: der Tag video-hit steht an jedem Import (144 echte Videos von 34'824), der Shopify-Dateispeicher ist voll (Upload FAILED), und das statische ffmpeg hat kein drawtext. Regel: bei einem Automaten, der dauerhaft nichts liefert, Quelle (gibt es Rohstoff?), Ablage (kann er das Ergebnis speichern?) und Werkzeug (kann er es ueberhaupt bauen?) einzeln messen. Loesung 22.09.: CJ queryVideosByProductId mit Referer, PIL-Textebenen, Ablage im Repo social/reels bis zum Grow-Plan.
