# Ursachen-Etikett darf keine Kategorie raten

Der Klingen-Waechter schrieb fuer jedes ungeklaerte Produkt «reaktiviert von unbekannt». Das Messerset Sternmuster war aber nie gedraftet: der Import legte es am 07.10. aktiv an (Titel damals «Stahlsatz», Handle zeigt es), eine spaetere Titel-Politur machte «Messerset». Das Etikett schickte die Suche zu einem Rueckholer, den es nicht gibt. Regel: ein Ursachen-Feld nennt nur, was ein Ereignis belegt (draft->active, created a new product); sonst «unbekannt». Und: Titel-Politur ist ein Eingangstor — Pruefungen, die nur beim Import laufen, sehen spaetere Umbenennungen nicht; der taegliche Waechter muss den Bestand lesen.
