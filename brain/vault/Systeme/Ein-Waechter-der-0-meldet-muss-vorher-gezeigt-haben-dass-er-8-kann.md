# Ein Wächter, der 0 meldet, muss vorher gezeigt haben, dass er 8 kann

Der erste Trockenlauf der Varianten-Wache über 25 Produkte ergab 0 fehlende Varianten — ohne die Positiv-Gegenprobe am bekannten Fall (Trainingsanzug, 8 von 40 Varianten bei CJ weg, per NUR_PID) wäre das eine stille Null gewesen. Ebenso lief der Kanarienvogel (25 frisch geprüfte: 25 ok) VOR der Stichprobe über alte Ledger-Einträge, sonst hätte eine CJ-Drossel wie «alles weg» ausgesehen. Regel: jeder Wächter, der draftet oder Massenurteile fällt, braucht (1) vor dem Lauf einen Kanarienvogel, der die Antwortfähigkeit beweist, und (2) einen Anlassfall, an dem er den Befund tatsächlich findet. Fehlen ALLE Shop-Varianten eines Produkts, ist das kein Befund, sondern Verdacht auf falsche SKU-Ableitung → unklar, nichts anfassen.
