# Ein Preis JE VARIANTE ist ehrlicher als ein Preis je Produkt

Bisher bekam ein Produkt meist EINEN neuen Preis, berechnet aus dem teuersten Einkauf seiner Varianten. Das ist sicher, aber es verteuert die kleinen Groessen ohne Grund. Diese Runde wurde die Regel je Variante gerechnet: neuer Preis = max(heutiger Preis, zielpreis(Einkauf dieser Variante)). GEMESSEN an 196 Produkten: 168 bekamen trotzdem genau EINEN Preis (ihre Einkaufspreise liegen beieinander), 28 bekamen eine Preisstaffel — genau die, deren Einkauf wirklich mit der Groesse steigt. Der Faktor-Deckel 3 gilt weiter, aber ebenfalls je Variante: bei einem Produkt koennen einzelne Varianten gesetzt und andere gemeldet werden. Das ist kein Widerspruch, sondern der ehrliche Befund.


**Traegt der Skill `messgeraet-zuerst`** — dort gehoert die Regel hinein, damit sie
sich beim naechsten passenden Auftrag von selbst laedt.
