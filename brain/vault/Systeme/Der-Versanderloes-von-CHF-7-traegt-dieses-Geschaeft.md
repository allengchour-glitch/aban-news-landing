# Der Versanderloes von CHF 7 traegt dieses Geschaeft

Gemessen ueber die sechs bezahlten Bestellungen mit belegtem Einkaufspreis: **29,0 % Nettomarge, CHF 9.20 Gewinn je Bestellung, AOV CHF 33.00, null Verluste.** Fuer CHF 1'000 Gewinn braucht es **109 Bestellungen**.

Die Gegenprobe ist der eigentliche Befund. Dieselben Bestellungen **ohne** den Versanderloes von CHF 7:

| | mit Versand | ohne |
|---|---|---|
| #1011 | +3.72 | **−2.98** |
| #1013 | +4.87 | **−1.82** |
| #1015 | +0.75 | **−5.94** |
| Verluste | 0 von 5 | **3 von 5** |

Bei uns ist Fracht eine **Stueckkost aus China**, kein Lagerfixkostenblock — jede Sendung kostet erneut. Die Gratisversand-Schwelle ist deshalb eine **Schutzmauer**, kein Conversion-Hindernis.

Damit ist der verbreitete Rat «Schwelle auf 15–30 % ueber dem AOV senken» hier **nicht anwendbar**: er setzt eine Kostenstruktur voraus, die wir nicht haben. Dasselbe gilt fuer den «40–60 % Rohmarge»-Benchmark — der finanziert Werbung, die wir nicht schalten.
