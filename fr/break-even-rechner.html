Calculer le break-even

À partir de combien d'unités vendues votre offre est-elle rentable ? Saisissez les coûts fixes, le prix de vente et les coûts variables par unité — vous voyez le seuil de rentabilité en unités et en chiffre d'affaires, la marge sur coûts variables et, en option, combien vous devez vendre pour atteindre un bénéfice cible. Tout en local dans votre navigateur, rien n'est envoyé.

Marge sur coûts variables par unité = prix de vente − coûts variables. Le seuil de rentabilité (break-even) est atteint lorsque les marges sur coûts variables couvrent les coûts fixes : unités = coûts fixes ÷ marge sur coûts variables. Si le prix n'est pas supérieur aux coûts variables, il n'y a pas de seuil de rentabilité. Les quantités sont arrondies vers le haut (on ne vend pas de demi-unités).
