Générer une Text-Shadow

Réglez les ombres de texte CSS avec des curseurs — position, flou, couleur et opacité — visualisez-les en direct sur un texte d'exemple et copiez le code text-shadow finalisé. Tout en local dans le navigateur, rien n'est envoyé.

Exemple
Horizontal (X)2px
Vertical (Y)2px
Flou4px
Opacité50%
CSS 

    
L'opacité contrôle l'alpha de la couleur de l'ombre (en rgba()). Des valeurs discrètes (petit décalage, un peu de flou, ~30–50 % d'opacité) rendent le mieux ; pour la lisibilité sur les images, une ombre sombre et douce aide. Tout en local, aucun téléversement.
