Générer une Flexbox

CSS flexbox concret : réglez flex-direction, justify-content, align-items, flex-wrap et gap, regardez les boîtes réagir en direct et copiez le code CSS du conteneur final. Tout en local dans votre navigateur, rien n'est envoyé.

CSS (conteneur) 

    
justify-content aligne le long de l'axe principal (la direction de flex-direction), align-items en travers. align-items: stretch n'a d'effet que lorsque les boîtes n'ont pas de taille fixe en travers de l'axe. Tout en local, aucun envoi.
