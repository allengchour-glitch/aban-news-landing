Échapper une chaîne JSON

Convertir du texte en chaîne JSON valide — les sauts de ligne, tabulations, guillemets et barres obliques inverses sont échappés correctement (\n \t \" \\) — ou reconvertir une chaîne JSON en texte brut. Tout est local dans le navigateur, rien n’est envoyé.

Résultat

L’échappement produit une valeur que vous pouvez insérer directement dans du JSON ou du code. Le dééchappement transforme une chaîne JSON (avec ou sans " englobants) en texte brut — y compris \uXXXX. Si l’entrée n’est pas une chaîne JSON valide, un avertissement apparaît. Tout est local, aucun téléversement.
