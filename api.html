aban API Live

Dieselbe KI, die hinter dem KI-Studio steckt — direkt per HTTP. Erzeuge KI-Texte, E-Mails, Pläne, Übersetzungen und mehr in deinen eigenen Tools, Skripten oder Automationen. Authentifizierung über deinen aban-Pro-Schlüssel — kein extra Account.

In 30 Sekunden

  1. aban Pro holen (enthält API-Zugang) — Pro ansehen →
  2. Deinen Lizenzschlüssel als API-Schlüssel verwenden (Header X-Pro-Key).
  3. POST an https://abannews.com/api/generate schicken.

Authentifizierung

Schick deinen aban-Pro-Schlüssel im Header X-Pro-Key (empfohlen) oder im JSON-Body als license_key. Ohne gültigen Schlüssel antwortet die API mit 402.

Endpunkt: Text erzeugen

POST /api/generate · Content-Type application/json

FeldPflichtBeschreibung
kindjaArt des Textes (siehe Liste unten). Standard: text.
brancheneinBranche/Kontext, z. B. „Handwerksbäckerei".
zielneinZiel/Zweck, z. B. „Kontaktaufnahme nach Messe".
textneinAusgangsmaterial (für rewrite, translate, summary, prompt, marketbrief).
tonneinTonalität, z. B. „sachlich, freundlich".
zielgruppeneinZielgruppe (Profi-Vorgabe).
laengeneinkurz · mittel · lang.

kind-Werte: text, email, newsletter, blog, faq, summary, social, ad, seo, slogan, landing, product, script, press, angebot, review, anleitung, ideas, jobad, plan, contentplan, emailserie, rewrite, translate, prompt, marketbrief.

Manche Arten nutzen Zusatzfelder: text (Ausgangsmaterial für rewrite/summary/review/translate/prompt/marketbrief) und plattform (für script, z. B. „Instagram").

Beispiel (curl)

curl -X POST https://abannews.com/api/generate \
  -H "Content-Type: application/json" \
  -H "X-Pro-Key: DEIN-PRO-SCHLUESSEL" \
  -d '{
    "kind": "email",
    "branche": "Handwerksbäckerei",
    "ziel": "Stammkunden über neue Öffnungszeiten informieren",
    "ton": "freundlich, kurz"
  }'

Beispiel (JavaScript / fetch)

const res = await fetch("https://abannews.com/api/generate", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Pro-Key": process.env.ABAN_PRO_KEY,
  },
  body: JSON.stringify({ kind: "social", branche: "Yoga-Studio", ziel: "Neuer Kurs ab Mai" }),
});
const data = await res.json();
console.log(data.text);

Antwort

{ "text": "…erzeugter Text…", "model": "claude-sonnet-4-6" }

Audit-Endpunkt

Für strukturierte KI-Sichtbarkeits-Reports: POST /api/audit-report (gleiche Auth). Felder: brand, website, branche, beschreibung, ziel. Antwort: { "report": "…", "grounded": true|false }. Mehr dazu: KI-Sichtbarkeits-Audit.

Status-Codes & Limits

CodeBedeutung
200OK — Ergebnis im Feld text bzw. report.
402Kein gültiger Pro-Schlüssel.
413Anfrage zu groß (max. 16 KB Body).
429Rate-Limit. /api/generate: 20/min (Jahres-Abo 60/min). /api/audit-report: 6/min (Jahr 20/min).
503KI vorübergehend nicht aktiv.
