Genera una sfumatura CSS

Componi una sfumatura di colori lineare o radiale con più punti colore e un angolo, vedila in tempo reale e copia il codice CSS background finito. Tutto in locale nel browser, niente viene inviato.

Angolo 135°
Punti colore
CSS 

    
Per la sfumatura radiale l'angolo viene ignorato (si irradia dal centro). I punti colore si spostano con il cursore (0–100 %). Suggerimento: per sfumature morbide scegli colori con luminosità simile. Tutto in locale, nessun caricamento.
