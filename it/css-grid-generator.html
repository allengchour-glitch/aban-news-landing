Genera una CSS Grid

Una griglia CSS concreta: imposta il numero di colonne e righe oltre agli spazi, vedi la griglia in tempo reale e copia il codice CSS del contenitore finito. Tutto in locale nel browser, niente viene inviato.

CSS (contenitore) 

    
repeat(N, 1fr) crea N colonne di uguale larghezza. column-gap e row-gap (insieme gap) sono gli spazi. In un layout reale posizioni i figli nella griglia — qui celle numerate mostrano la griglia. Tutto in locale, nessun upload.
