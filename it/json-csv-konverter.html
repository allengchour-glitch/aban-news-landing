Convertire JSON ↔ CSV

Trasforma un array JSON di oggetti in una tabella CSV — o viceversa. Con corretto escape delle virgolette (RFC 4180), separatore a scelta, copia e download. Tutto in locale nel browser, niente viene inviato.

Risultato

JSON → CSV si aspetta un array di oggetti; le colonne sono l'unione di tutte le chiavi. I valori annidati vengono scritti nella cella come testo JSON. CSV → JSON prende la prima riga come intestazioni di colonna. Tutto in locale, senza upload.
