Esegui l’escape di una stringa JSON

Converti il testo in una stringa JSON valida — interruzioni di riga, tabulazioni, virgolette e barre rovesciate vengono sottoposte a escape correttamente (\n \t \" \\) — oppure riconverti una stringa JSON in testo semplice. Tutto in locale nel browser, niente viene inviato.

Risultato

L’escape produce un valore che puoi inserire direttamente in JSON o nel codice. L’annullamento dell’escape trasforma una stringa JSON (con o senza " circostanti) in testo semplice — incluso \uXXXX. Se l’input non è una stringa JSON valida, compare un avviso. Tutto in locale, nessun caricamento.
