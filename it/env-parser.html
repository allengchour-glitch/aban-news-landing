.env & header → JSON

Converti un file .env o un blocco di header HTTP in un oggetto JSON — e viceversa. Comodo quando uno strumento webhook o API si aspetta gli header in formato JSON. In locale nel browser, niente viene inviato.

—
Nota: token e password restano nel tuo browser — questa pagina non invia nulla. Tuttavia: meglio incollare veri secret di produzione solo dove servono davvero.

Riconosce KEY=value (.env) e Nome: valore (header). I commenti (#) e le righe vuote vengono ignorati, le virgolette esterne vengono rimosse. Tutto in locale.
