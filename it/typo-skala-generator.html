Crea una scala tipografica

Una scala di dimensioni dei caratteri armoniosa a partire da una dimensione di base e un rapporto — la base di ogni buon sistema tipografico. Ottieni valori in px e rem e variabili CSS pronte da copiare. Tutto funziona in locale nel browser, niente viene inviato.

Variabili CSS 

    
Ogni passo = dimensione di base × rapporto^passo. Il passo 0 è la dimensione di base (testo corrente). rem si riferisce allo standard del browser di 16 px. Suggerimento: rapporti più piccoli (1.125–1.25) per pagine ricche di testo, più grandi (1.5–1.618) per titoli espressivi. Tutto in locale, nessun caricamento.
