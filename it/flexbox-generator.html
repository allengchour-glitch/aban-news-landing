Genera una Flexbox

CSS flexbox alla mano: imposta flex-direction, justify-content, align-items, flex-wrap e gap, guarda le caselle reagire dal vivo e copia il codice CSS del contenitore finale. Tutto in locale nel browser, niente viene inviato.

10px
CSS (contenitore) 

    
justify-content allinea lungo l'asse principale (la direzione di flex-direction), align-items in senso trasversale. align-items: stretch ha effetto solo quando le caselle non hanno una dimensione fissa trasversale all'asse. Tutto in locale, nessun upload.
