Immagine in Base64

Convertire un'immagine in un data-URI Base64 — utile per piccole icone, firme e-mail o CSS, quando non si vuole caricare un file esterno. Con snippet <img> e CSS pronti all'uso. Tutto in locale nel browser, senza upload.

Trascina qui un'immagine o fai clic

PNG, JPG, GIF, WebP, SVG · max. ~2 MB consigliato

HTML
CSS

Il Base64 rende i dati ~33% più grandi del file originale — ideale per piccole immagini/icone, non per foto grandi. L'SVG spesso può anche essere incorporato direttamente. Tutto avviene in locale nel browser, niente viene caricato.
