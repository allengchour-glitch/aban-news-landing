# Gemini Site-Kritik — 2026-06-09

**Gesamtnote: 6/10**

## ✅ Stärken
- Klarer Nutzenversprechen und Zielgruppenansprache im Hero und auf Kategorieseiten.
- Hochwertige Bildsprache und Premium-Anmutung.
- Gute CH-spezifische Trust-Signale (CHF, TWINT, Versand/Rückgabe Infos).
- Aktuelle und relevante Inhalte ('Sommer-Mode 2026').

## 🔧 Kritische Probleme (nach Priorität)

### 🔴 [Mobil/Performance] Cookie Banner überdeckt auf Mobil kritische Inhalte (CTA, Produktkacheln, Titel). Auf Desktop ebenfalls störend.
- **Fix:** Banner als dezentes, fixiertes Element am unteren Bildschirmrand platzieren oder als Modal, das den Hintergrund dimmt, aber nicht verschiebt.
- **Umsetzbar per:** Theme-Customizer

### 🔴 [Trust/Funnel] Lieferzeit von '7-14 Tage' ist für Premium-Mode im Schweizer Markt zu lang und ein starker Conversion-Killer.
- **Fix:** Lieferprozess optimieren oder Kommunikation anpassen (z.B. 'Lieferzeit 1-2 Wochen' oder Mehrwert der Wartezeit betonen).
- **Umsetzbar per:** Copy

### 🔴 [Trust/Produktkacheln] Keine Sternebewertungen auf Produktkacheln sichtbar, obwohl 'Kund:innen-Bewertungen' erwähnt werden. Verpasste Social Proof.
- **Fix:** Sternebewertungen prominent auf allen Produktkacheln anzeigen.
- **Umsetzbar per:** API

### 🟡 [Produktkacheln/Mobil] Produktnamen auf Mobil (z.B. 'Stiletto-Sandalette «Gala» Violett Knöchelriemen') werden abgeschnitten.
- **Fix:** Produktnamen kürzen oder Schriftgrösse/Zeilenumbruch anpassen, um vollständige Lesbarkeit zu gewährleisten.
- **Umsetzbar per:** Copy

### 🟢 [Typografie/Mobil] Schrift in der Top-Bar ('Gratis-Versand ab CHF 65...') ist auf Mobil sehr klein und schwer lesbar.
- **Fix:** Schriftgrösse erhöhen oder die wichtigsten Infos prominenter hervorheben und den Rest in einem Tooltip/separaten Link.
- **Umsetzbar per:** Theme-Customizer

## ⚡ Quick Wins
- Cookie Banner sofort weniger invasiv gestalten (Positionierung, Grösse).
- Lieferzeit-Kommunikation auf Kategorieseite überarbeiten.
- Produktbewertungen auf Produktkacheln aktivieren/anzeigen.
- Produkt-Titel auf Mobil kürzen/anpassen.
- Schriftgrösse der Top-Bar auf Mobil erhöhen.
- Sticky CTA für den Hero-Bereich auf Mobil in Betracht ziehen.
