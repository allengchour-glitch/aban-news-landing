CSS Grid generieren

Ein CSS-Raster zum Anfassen: Spalten- und Zeilenzahl sowie Abstände einstellen, das Grid live sehen und den fertigen Container-CSS-Code kopieren. Alles lokal im Browser, nichts wird gesendet.

CSS (Container) 

    
repeat(N, 1fr) erzeugt N gleich breite Spalten. column-gap und row-gap (zusammen gap) sind die Abstände. Im echten Layout setzt du die Kinder ins Grid — hier zeigen nummerierte Zellen das Raster. Alles lokal, kein Upload.
