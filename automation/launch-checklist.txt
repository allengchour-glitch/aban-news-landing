A) Technik / Setup
================================================================

[ ] Domain abannews.com beim Registrar auf Cloudflare-Nameserver zeigen lassen
[ ] In Cloudflare DNS den Eintrag für abannews.com auf das Pages-Projekt setzen
    (Custom Domain im Pages-Projekt hinzufügen, www -> apex weiterleiten)
[ ] HTTPS prüfen: https://abannews.com öffnet ohne Zertifikatswarnung
[ ] Cloudflare Pages Deploy prüfen: letzter Push auf main ist live
    (kein Build-Command, Output = Repo-Root; _redirects + _headers erkannt)
[ ] Alle Subscribe-Buttons zeigen auf https://abannews.beehiiv.com/subscribe
    — index.html und alle Subpages durchklicken (Hero, Footer, SEO-Money-Pages,
      ebook.html, resources.html, willkommen.html, founding.html)
[ ] _redirects testen: https://abannews.com/buch -> buch.html lädt
[ ] _redirects testen: https://abannews.com/ebook -> erwartete Zielseite lädt
[ ] Sprach-Pfade prüfen: /en/, /fr/, /it/ erreichbar, hreflang korrekt
[ ] sitemap.xml enthält alle Live-Seiten (auch buch.html + Sprach-Varianten)
[ ] Google Search Console: Property abannews.com anlegen, Eigentum bestätigen
[ ] In der Search Console sitemap.xml einreichen
    (https://abannews.com/sitemap.xml)
[ ] robots.txt erlaubt Crawling und verweist auf die Sitemap
