# So holst du in 1 Woche das Meiste aus der Bibliothek

- [ ] **Tag 1:** Eine wiederkehrende Schreib-Aufgabe wählen (z. B. Mails,
      Angebote, Social-Posts) und den passenden Prompt kopieren.
- [ ] **Tag 2-3:** Prompt mit deinen echten Infos füllen, Ergebnis gegenlesen,
      einmal nachschärfen lassen („kürzer / direkter / wärmer").
- [ ] **Tag 4:** Den besten Prompt mit deinen Standard-Angaben als eigene
      Vorlage speichern (z. B. in einem Notiz-Dokument).
- [ ] **Tag 5:** Eine zweite Kategorie ausprobieren (z. B. Recherche oder
      Admin) — eine neue Routine reicht.
- [ ] **Laufend:** Was gut lief, sammeln. Was nicht passte, weglassen. Deine
      eigene Mini-Bibliothek wächst von selbst.

**Drei Regeln, die du nie vergessen solltest:**

1. Fakten, Zahlen und Namen kommen von dir — KI rät sonst.
2. Für Sensibles (Kundendaten, Verträge) nur Tools mit klarer
   EU-Datenverarbeitung nutzen.
3. Nichts ungeprüft rausschicken. Der letzte Blick ist deiner.
