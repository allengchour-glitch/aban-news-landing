# AI-Sichtbarkeit — Startpaket für Aban (Schritt für Schritt, ohne Vorwissen)

> Du brauchst kein Vorwissen. Mach genau das hier, von oben nach unten.
> Heute reichen **30 Minuten**. Ziel: **eine** ehrliche Mail an **einen** echten
> Betrieb. Mehr nicht. Der Rest kommt, wenn der erste Schritt sitzt.
>
> Verbundene Dateien: Angebot/Preise → `docs/AI-SICHTBARKEIT-ANGEBOT.md`,
> Report-Rahmen → `docs/AI-SICHTBARKEIT-REPORT-VORLAGE.md`.

---

## Die Idee in einem Satz
Firmen wollen wissen, ob sie in ChatGPT & Co. auftauchen, wenn ein Kunde nach
ihrer Branche fragt. Die meisten **tauchen nicht auf**. Du prüfst das und sagst
ihnen, was zu tun ist. Dafür zahlen sie.

---

## SCHRITT 1 — Such dir 5 Firmen (10 Min)

Nimm Firmen, die du **kennst** oder leicht findest. Keine Konzerne — Mittelstand,
lokale Betriebe, Dienstleister. Beispiele, wo du suchen kannst:
- Betriebe, bei denen du Kunde bist (Zahnarzt, Garage, Steuerberater, Handwerker).
- Firmen aus deiner Region (Google Maps: „[Branche] [deine Stadt]").
- Aus unseren eigenen Daten: `handwerk-radar/data/anbieter.json` (55 echte Betriebe
  mit Website) — perfekte Übungsziele.

Trag sie hier ein (Name + Website + 1 Branchen-Frage, die ein Kunde stellen würde):

| # | Firma | Website | Typische Kundenfrage |
|---|-------|---------|----------------------|
| 1 |       |         | z. B. „Wer installiert Wärmepumpen in [Stadt]?" |
| 2 |       |         | |
| 3 |       |         | |
| 4 |       |         | |
| 5 |       |         | |

> Schaffst du nur 1 Firma heute? Auch gut. Eine reicht zum Starten.

---

## SCHRITT 2 — Der Gratis-Check (5 Min pro Firma)

So findest du heraus, ob die Firma in KI-Antworten auftaucht. Ganz konkret:

1. Geh auf **chatgpt.com** (kostenlos) — oder **perplexity.ai**.
2. Tipp die **Kundenfrage** aus deiner Tabelle ein, z. B.:
   *„Welche Betriebe installieren Wärmepumpen in Augsburg?"*
3. Schau in die Antwort:
   - Wird **die Firma genannt?**  → Notiere: ja / nein.
   - Werden **Wettbewerber** genannt?  → Notiere 1–2 Namen.
4. Stell eine zweite, leicht andere Frage (z. B. „beste …" oder „… in meiner Nähe").
5. Fertig. Du hast jetzt einen echten Befund: „Firma X taucht nicht auf,
   Wettbewerber Y schon." **Das** ist dein Aufhänger.

> Das ist der „kostenlose 1-Seiten-Check". Mehr Technik brauchst du für die
> erste Mail nicht.

---

## SCHRITT 3 — Die Mail (5 Min)

Kopier das, ersetz die **[eckigen Klammern]** mit deinem Befund aus Schritt 2,
und schick es an die Kontakt-Adresse der Firma (Impressum/Website):

```
Betreff: [Firma] taucht in ChatGPT nicht auf — ein kurzer Hinweis

Guten Tag,

ich habe [Firma] testweise durch die gängigen KI-Antwortmaschinen laufen
lassen (ChatGPT, Perplexity). Bei der Frage „[deine Kundenfrage]" werden Sie
aktuell nicht genannt — [Wettbewerber] schon.

Immer mehr Kunden recherchieren so. Wer dort nicht auftaucht, wird nicht
gefunden. Das lässt sich beheben.

Wenn es Sie interessiert, schicke ich Ihnen kostenlos eine kurze Übersicht mit
den 3 größten Lücken — ohne Verkaufsgespräch. Sagen Sie einfach kurz Bescheid.

Freundliche Grüsse
Aban — abannews.com
```

> Das ist **keine** Lüge und **kein** Spam: Du hast wirklich geprüft, du hilfst
> zuerst gratis, du verkaufst nichts im ersten Schritt. Genau der ehrliche Ton
> deiner Marke.

## SCHRITT 4 — Wenn jemand antwortet (erst dann!)

Glückwunsch — jetzt erst geht's ums Geld. Du schickst die Preis-Mail aus
`docs/AI-SICHTBARKEIT-ANGEBOT.md` (Block „B) Antwort auf was kostet das?"):

- **Voll-Audit: €300–900** (du prüfst 5–15 Seiten, lieferst eine Maßnahmenliste).
- **Monats-Report: €89–199/Monat** (optional, danach).
- Ehrlich: „Aufbauphase, Pilot-Preis, Geld zurück wenn's nichts bringt."

Den Audit selbst machst du mit dem Rahmen in
`docs/AI-SICHTBARKEIT-REPORT-VORLAGE.md` — da führe ich dich durch, sobald du
den ersten Kunden hast.

---

## Die Wahrheit, die dich trägt
- **Absagen sind normal.** 4 von 5 sagen nichts. Das ist kein Scheitern, das ist
  das Spiel. Du brauchst **ein** Ja.
- **Ein einziger Audit (€300–900)** bringt mehr als alle 7 Radars dieses Jahr.
- Du musst **nicht** perfekt sein. Du musst nur **die erste Mail abschicken.**
