## Description (für das PH-Feld)

```
The Hype-Filter checks German marketing or website copy and shows you, instantly,
how much empty hype is in it: buzzwords, filler words, vague promises, passive
voice, readability — with concrete suggestions to fix each one.

No login, no tracking, no upsell. Paste text, get an honest score and a rewrite
direction. Built for solopreneurs and small teams who want copy that sounds human,
not like a press release.

Why I built it: I write a daily AI newsletter for German-speaking professionals
and got tired of "revolutionary, game-changing, AI-powered" everything. So I made
the tool I wanted — a calm second opinion that flags the fluff.

It also works as an embeddable widget (one script tag, style-isolated) and has a
small open engine behind it. Free, and staying free.
```
