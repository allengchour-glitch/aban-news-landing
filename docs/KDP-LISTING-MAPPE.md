## Reihenfolge (so gehst du vor)

1. **KDP-Konto** auf kdp.amazon.com (Steuer-Interview + Bankverbindung) — einmalig, nur du.
2. **Mit Deutsch starten** (dein stärkster Markt): „Create" → Kindle eBook →
   Titel/Untertitel/Beschreibung/Keywords/Kategorien aus dem 🇩🇪-Block einsetzen →
   `anti-hype-ebook.epub` + `kdp-cover-ebook.png` hochladen → Preis → Publish.
3. **Direkt danach Taschenbuch** (gleiches Buch, „Create Paperback"):
   `anti-hype-print-de.pdf` + `kdp-cover-paperback.png` → Preis → Publish.
4. **EN/FR/IT** genauso wiederholen (je eigenes Buch).
5. Fertig. Amazon verkauft, druckt, liefert, zahlt aus — **null Kontakt.**

> Nach dem Live-Gang: die Amazon-Links auf `buch.html` ergänzen (Querverweis),
> und optional Direktverkauf über Lemon Squeezy (`js/buch-config.js`) für höhere Marge.
