# „Newsletter-Autopilot" als Bausatz verkaufen (Grundgerüst)

**Idee:** Du hast einen seltenen, funktionierenden, **gratis betreibbaren** Automations-Stack
(Content-Engine, Bild-Pipeline, Autopilot, Autopost — alles über GitHub Actions, keine Server).
Den als **Boilerplate/Template** verkaufen — anderen Indie-Newsletter-Machern spart er Wochen.

## Was schon da ist
- `tools/export_template.py` — exportiert die generischen Bausteine nach `dist-template/`
  (OHNE Secrets, OHNE deine Inhalte/Queues, mit leeren Vorlagen + README).

## So machst du ein Produkt draus
1. `python3 tools/export_template.py` → `dist-template/` prüfen.
2. Lizenz wählen (z. B. „privat + 1 Projekt") + in README ergänzen.
3. Als ZIP in **Lemon Squeezy/Gumroad** verkaufen **oder** als Open-Core-GitHub-Repo (Sponsoring).
4. Marketing: „build in public" — zeig die echte Maschine (dieser Newsletter) als Referenz.

## Geld
- Einmalig **€29–49** pro Verkauf (digital, MoR regelt Steuer). Optional „Pro"-Version mit Extras.
- Bonus-Funnel: Käufer abonnieren aban news → wärmt deine eigene Liste.

## Ehrlich
- Es ist ein **Bausatz für Technik-affine** Leute (GitHub/Actions nötig) — klar kommunizieren.
- Kein „verdiene-im-Schlaf"-Versprechen: Käufer müssen eigene Keys/Inhalte mitbringen.
- Support kostet Zeit → Doku gut machen, Scope klein halten.
