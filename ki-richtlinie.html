KI-Richtlinie fürs Team

Ein paar Klicks → eine klare, einseitige Nutzungsregel: welche KI-Tools erlaubt sind, welche Daten tabu, wann geprüft wird. Zum Kopieren oder Drucken. Läuft im Browser, kein Datenversand.

⚖️ Das ist eine Vorlage zum Selbermachen, keine Rechtsberatung. Sie hilft, ein gemeinsames Verständnis im Team zu schaffen. Für verbindliche Vorgaben (besonders bei sensiblen Daten oder regulierten Berufen) zieh eine Datenschutz-/Rechts-Fachperson hinzu.

Warum dein Team eine KI-Richtlinie braucht

Sobald mehrere Menschen KI-Tools nutzen, entstehen ohne klare Regeln schnell Graubereiche: Eine Person tippt Kundennamen in die Gratis-Version eines Chatbots, eine andere lädt einen Vertragsentwurf hoch, eine dritte übernimmt eine KI-Antwort ungeprüft an einen Kunden. Jeder dieser Fälle kann teuer werden — über den Datenschutz oder über einen Fehler, den niemand bemerkt hat. Eine kurze, gemeinsame Richtlinie nimmt diese Unsicherheit raus. Sie sagt klar, welche Tools erlaubt sind, welche Daten tabu bleiben und wann ein Mensch gegenprüft. So kann das Team KI selbstbewusst nutzen, statt aus Angst gar nicht oder unkontrolliert.

So entsteht deine Richtlinie

Du beantwortest ein paar Fragen — erlaubte Tools, Tabu-Daten, Prüfpflicht, Ansprechperson — und das Werkzeug setzt daraus eine saubere, einseitige Nutzungsregel zusammen, die du kopieren oder ausdrucken kannst. Es ist eine Vorlage zum Selbermachen, die ein gemeinsames Verständnis schafft, und ausdrücklich keine Rechtsberatung. Für verbindliche Vorgaben — besonders bei sensiblen Daten oder in regulierten Berufen — sollte eine Datenschutz- oder Rechts-Fachperson drüberschauen. Alles läuft im Browser, deine Eingaben werden nicht gespeichert.

Häufige Fragen

Ist die Richtlinie rechtlich verbindlich?

Sie ist eine interne Arbeitsgrundlage, kein Rechtsdokument. Sie schafft Klarheit im Team. Für verbindliche oder haftungsrelevante Vorgaben lass sie von einer Fachperson prüfen und intern offiziell verabschieden.

Was, wenn wir KI noch gar nicht einsetzen?

Dann ist es der ideale Zeitpunkt. Regeln vorab zu setzen ist viel leichter, als später Wildwuchs einzufangen. Du legst einfach fest, was erlaubt sein soll, bevor es losgeht.

Werden meine Eingaben gespeichert?

Nein. Die Richtlinie wird vollständig lokal in deinem Browser erzeugt — kein Upload, kein Konto.

Bin ich damit DSGVO-konform?

Eine Richtlinie ist ein wichtiger Baustein, aber nicht alles. Prüf zusätzlich den DSGVO-Schnellcheck und fordere bei Anbietern mit dem AVV-Anfrage-Generator den nötigen Vertrag an.
